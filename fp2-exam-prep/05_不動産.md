# 第5分野 不動産(学科 問41〜50)

## 頻出論点まとめ(過去10年の出題傾向)

### ★★★ ほぼ毎回出題
1. **不動産登記**
   - 登記には**対抗力はあるが公信力はない**(登記を信じて無権利者から買っても保護されない)。
   - 構成: 表題部(物理的現況)・権利部**甲区(所有権)**・**乙区(所有権以外**: 抵当権・賃借権等**)**。
   - **登記事項証明書は誰でも**手数料を払えば交付請求できる。
   - **仮登記には対抗力はない**(順位保全効力のみ)。
2. **不動産の価格(4つ+1)**(超頻出・表で暗記)

   | 価格 | 決定機関 | 基準日 | 目安 |
   |---|---|---|---|
   | 公示価格 | 国土交通省 | 毎年1月1日 | 100% |
   | 基準地標準価格 | 都道府県 | 毎年**7月1日** | 100% |
   | 相続税路線価 | 国税庁 | 毎年1月1日 | 公示価格の**80%** |
   | 固定資産税評価額 | 市町村 | 1月1日(**3年ごと**評価替え) | 公示価格の**70%** |
3. **宅建業法・売買契約**
   - 媒介契約: **一般**(複数業者・自己発見OK、報告義務なし)/**専任**(1業者、自己発見OK、有効期間**3ヶ月**、報告**2週間に1回以上**、レインズ登録7日以内)/**専属専任**(自己発見も不可、報告**1週間に1回以上**、レインズ5日以内)。
   - **手付金(解約手付)**: 相手方が履行に着手するまでは、**買主は放棄・売主は倍額を現実に提供**して解除できる。宅建業者が自ら売主の場合、手付は代金の**2割まで**。
   - 危険負担・契約不適合責任: 買主は不適合を**知った時から1年以内に通知**すれば、追完請求・代金減額請求・損害賠償・解除が可能。
4. **借地借家法**(超頻出)
   - **普通借地権**: 存続期間**30年以上**(定めなし・30年未満→30年)。更新後は1回目20年・以後10年。
   - **定期借地権3種**:

     | 種類 | 存続期間 | 利用目的 | 契約方式 |
     |---|---|---|---|
     | 一般定期借地権 | **50年以上** | 制限なし | **書面(電磁的記録可)** |
     | 事業用定期借地権等 | **10年以上50年未満** | **事業用のみ(居住用不可)** | **公正証書に限る** |
     | 建物譲渡特約付借地権 | 30年以上 | 制限なし | 制限なし |
   - **普通借家権**: 期間1年未満の定め→**期間の定めのないもの**とみなす。貸主からの更新拒絶には**正当事由**が必要。
   - **定期借家権**: **書面(電磁的記録可)**で契約+**事前に書面等で説明**。1年以上の契約では期間満了の**1年前から6ヶ月前まで**に終了通知。床面積**200㎡未満の居住用**は転勤等やむを得ない事情があれば借主から中途解約可。
   - 造作買取請求権・遺言・特約で排除可能なもの: 造作買取請求権は**特約で排除可**。
5. **区分所有法**
   - 集会の決議: 一般的事項は過半数/**規約の設定・変更・廃止、共用部分の重大変更は3/4以上**/**建替えは4/5以上**。
   - 専有部分と敷地利用権の**分離処分は原則不可**。集会は年1回以上招集。
6. **都市計画法**
   - 市街化区域=すでに市街地+おおむね10年以内に優先的・計画的に市街化を図る区域(**用途地域を定める**)。市街化調整区域=市街化を抑制(原則、用途地域を定めない)。
   - **開発許可**: 市街化区域では**1,000㎡以上**の開発行為に必要。市街化調整区域では**規模にかかわらず**必要(農林漁業用建築物等を除く)。
7. **建築基準法**(計算問題は実技でも毎回)
   - **接道義務**: 幅員**4m以上**の道路に**2m以上**接する。**2項道路**は道路中心線から**2m**後退した線が道路境界線とみなされる(セットバック部分は建蔽率・容積率の計算上、敷地面積に**算入しない**)。
   - **建蔽率の緩和**: 防火地域内の耐火建築物等**+10%**/特定行政庁指定の角地**+10%**(両方で+20%)。**建蔽率80%の地域内かつ防火地域内の耐火建築物等→100%(制限なし)**。
   - **容積率**: 前面道路(2以上あれば**最も広いもの**)の幅員が**12m未満**の場合、「幅員×**4/10**(住居系)または**6/10**(その他)」と指定容積率の**低い方**。
   - 敷地が2つの用途地域にまたがる場合: 用途制限は**過半の属する地域**、建蔽率・容積率は**加重平均**、防火規制は**厳しい方**。
8. **農地法**
   - **3条(権利移動)=農業委員会**の許可/**4条(転用)・5条(転用目的の権利移動)=都道府県知事等**の許可。
   - **市街化区域内**の農地の転用(4条・5条)は、あらかじめ**農業委員会への届出**でよい(許可不要)。
9. **不動産の取得・保有の税金**
   - 不動産取得税: 都道府県税。**相続による取得は非課税**(贈与は課税)。課税標準は固定資産税評価額。新築住宅**1,200万円控除**(認定長期優良住宅1,300万円)。宅地は課税標準1/2。
   - 登録免許税(相続登記も課税)・印紙税・消費税(**土地は非課税**、建物は課税〔個人間の中古住宅売買は非課税〕)。
   - **固定資産税**: **1月1日**現在の所有者に課税。標準税率1.4%。**住宅用地200㎡以下の部分は課税標準1/6**(超える部分1/3)。新築住宅の税額1/2軽減(3年or5年、120㎡まで)。年の途中で売却しても**その年分は1月1日の所有者が納税義務者**。
   - 都市計画税: 市街化区域内、制限税率0.3%、住宅用地1/3(200㎡以下)。
10. **譲渡所得と特例**(超頻出)
    - 長期・短期: **譲渡した年の1月1日**時点で所有期間**5年超→長期(20.315%)**、5年以下→短期(39.63%)。
    - 取得費不明→**概算取得費(譲渡収入×5%)**。相続で取得→被相続人の取得時期・取得費を引き継ぐ。
    - **居住用財産の3,000万円特別控除**: 所有期間の長短**不問**。配偶者・直系血族等への譲渡は不可。住まなくなってから**3年後の年末まで**。前年・前々年に適用を受けていると不可(3年に1度)。
    - **軽減税率の特例**: 譲渡年1月1日で所有**10年超**の居住用→3,000万円控除**後**の6,000万円以下の部分**14.21%**。**3,000万円控除と併用可**。
    - 特定居住用財産の買換え特例(3,000万円控除・軽減税率と**選択適用**)。
    - **被相続人の居住用財産(空き家)の3,000万円特別控除**: 1981年5月31日以前建築、相続から**3年後の年末まで**、譲渡対価**1億円以下**、耐震改修または取壊しが要件。
11. **不動産の有効活用・投資**
    - 事業方式: **等価交換方式**(土地を拠出し建物床と交換、資金不要)/**事業受託方式**/**建設協力金方式**(テナントの預り金で建設)/**定期借地権方式**(土地を貸すだけ)。
    - **NOI利回り(純利回り)=(年間総収入−年間諸経費)÷投資総額×100**(計算頻出)。表面利回り=年間総収入÷投資総額。
    - DCF法・直接還元法(収益還元法)、DSCR(借入金償還余裕率)。

## 対策問題(10問)

### 問1 不動産登記
不動産登記に関する次の記述のうち、**最も適切**なものはどれか。

1. 不動産登記には公信力が認められているため、登記記録を信頼して取引した者は原則として保護される。
2. 抵当権に関する登記事項は、登記記録の権利部甲区に記録される。
3. 登記事項証明書は、対象不動産の所有者本人でなければ交付を請求できない。
4. 所有権移転の仮登記をしても、その後の第三者への所有権移転登記を妨げる効力(対抗力)はない。

### 問2 不動産の価格
土地の価格に関する次の記述のうち、**最も不適切**なものはどれか。

1. 地価公示の公示価格は、毎年1月1日を基準日として国土交通省の土地鑑定委員会が公表する。
2. 都道府県地価調査の基準地標準価格は、毎年7月1日を基準日としている。
3. 相続税路線価は、地価公示の公示価格の70%を価格水準の目安として設定されている。
4. 固定資産税評価額は、原則として3年ごとの基準年度において評価替えが行われる。

### 問3 宅建業法(媒介契約)
宅地建物取引業法に基づく媒介契約に関する次の記述のうち、**最も不適切**なものはどれか。

1. 一般媒介契約では、依頼者は複数の宅建業者に重ねて媒介を依頼することができる。
2. 専任媒介契約の有効期間は、3ヶ月を超えることができない。
3. 専任媒介契約を締結した宅建業者は、依頼者に対し、業務の処理状況を1週間に1回以上報告しなければならない。
4. 専属専任媒介契約では、依頼者は自ら発見した相手方と売買契約を締結することができない。

### 問4 借地借家法(借地)
借地借家法に関する次の記述のうち、**最も適切**なものはどれか。

1. 普通借地権の存続期間を20年と定めた場合、その期間は20年となる。
2. 一般定期借地権の存続期間は50年以上とし、契約は公正証書によらなければならない。
3. 事業用定期借地権等の設定契約は、公正証書によってしなければならない。
4. 事業用定期借地権等は、従業員向け社宅など居住用の建物の所有を目的とする場合にも設定できる。

### 問5 借地借家法(借家)
借地借家法に関する次の記述のうち、**最も不適切**なものはどれか。

1. 期間の定めのある普通借家契約において、期間を1年未満と定めた場合、期間の定めのない契約とみなされる。
2. 普通借家契約で、賃貸人が更新を拒絶するには正当事由が必要である。
3. 定期借家契約は、公正証書等の書面(または電磁的記録)によって締結しなければならない。
4. 定期借家契約では、契約期間にかかわらず、賃借人からの中途解約は一切認められない。

### 問6 区分所有法
建物の区分所有等に関する法律に関する次の記述のうち、**最も不適切**なものはどれか。

1. 規約の設定・変更・廃止は、区分所有者および議決権の各4分の3以上の多数による集会の決議が必要である。
2. 建替え決議は、区分所有者および議決権の各5分の4以上の多数により行う。
3. 専有部分と敷地利用権は、規約に別段の定めがない限り、分離して処分することができない。
4. 集会の招集は、少なくとも2年に1回行えばよい。

### 問7 建築基準法(建蔽率・容積率)
建築基準法に関する次の記述のうち、**最も不適切**なものはどれか。

1. 建築物の敷地は、原則として、幅員4m以上の道路に2m以上接していなければならない。
2. 指定建蔽率80%の地域内で、かつ防火地域内にある耐火建築物等については、建蔽率の制限が適用されない。
3. 前面道路の幅員が12m未満の場合、容積率は「指定容積率」と「前面道路幅員×法定乗数」のいずれか高い方が適用される。
4. いわゆる2項道路では、原則として道路中心線から水平距離2m後退した線が道路境界線とみなされ、セットバック部分は建蔽率・容積率の計算上、敷地面積に算入されない。

### 問8 農地法
農地法に関する次の記述のうち、**最も適切**なものはどれか。

1. 農地を農地のまま売買する場合(権利移動)は、原則として都道府県知事等の許可が必要である。
2. 市街化区域内の農地を宅地に転用する場合、あらかじめ農業委員会に届け出れば、都道府県知事等の許可は不要である。
3. 農地を転用目的で取得する場合(5条)、農業委員会の許可を受ければよい。
4. 相続により農地を取得する場合、農地法3条の許可が必要である。

### 問9 固定資産税・不動産取得税
不動産に係る税金に関する次の記述のうち、**最も不適切**なものはどれか。

1. 不動産取得税は、相続により不動産を取得した場合には課されない。
2. 固定資産税は、毎年1月1日現在の固定資産の所有者に課される。
3. 住宅用地に係る固定資産税の課税標準は、200㎡以下の部分について、価格の3分の1となる。
4. 年の途中に土地を売却した場合でも、その年度分の固定資産税の納税義務者は1月1日現在の所有者である。

### 問10 居住用財産の譲渡の特例
居住用財産を譲渡した場合の特例に関する次の記述のうち、**最も不適切**なものはどれか。

1. 「3,000万円特別控除」は、譲渡した年の1月1日における所有期間が5年以下であっても適用を受けることができる。
2. 「3,000万円特別控除」は、配偶者に譲渡した場合には適用を受けることができない。
3. 「軽減税率の特例」は、譲渡した年の1月1日における所有期間が10年を超える居住用財産に適用され、3,000万円特別控除と併用できる。
4. 課税長期譲渡所得に対する税率は、所得税・住民税合わせて39.63%である。

## 解答・解説

**問1 正解 4** — 仮登記は順位保全の効力のみで対抗力なし。1: 公信力は**ない**。2: 抵当権は**乙区**。3: 誰でも請求可。

**問2 正解 3** — 路線価は公示価格の**80%**水準(70%は固定資産税評価額)。

**問3 正解 3** — 専任媒介の報告義務は**2週間に1回以上**(1週間に1回以上は専属専任)。

**問4 正解 3** — 事業用定期借地権等は**公正証書必須**。1: 30年未満の定めは30年になる。2: 一般定期借地権は書面であれば公正証書でなくてよい。4: 居住用(社宅・賃貸マンション含む)は不可。

**問5 正解 4** — 床面積**200㎡未満の居住用建物**では、転勤・療養等やむを得ない事情があれば借主から中途解約できる(申入れから1ヶ月で終了)。

**問6 正解 4** — 集会は**少なくとも毎年1回**招集しなければならない。

**問7 正解 3** — 指定容積率と前面道路幅員×法定乗数の**いずれか低い方**が適用される。

**問8 正解 2** — 市街化区域内の転用(4条・5条)は農業委員会への**届出**で足りる。1: 権利移動(3条)は**農業委員会**の許可。3: 5条は都道府県知事等の許可。4: 相続による取得に3条許可は不要(農業委員会への届出は必要)。

**問9 正解 3** — 住宅用地200㎡以下(小規模住宅用地)の固定資産税の課税標準は**6分の1**(3分の1は200㎡超の部分と都市計画税)。

**問10 正解 4** — 課税**長期**譲渡所得の税率は**20.315%**(39.63%は短期)。1〜3は特例の正しい理解として頻出。
