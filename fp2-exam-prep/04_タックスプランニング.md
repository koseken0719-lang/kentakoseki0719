# 第4分野 タックスプランニング(学科 問31〜40)

> **2025年度税制改正の重要ポイント(2026年度試験から反映)**
> - 基礎控除: 48万円 → **58万円**(合計所得金額2,350万円以下。当面の間、低所得層には上乗せ特例あり)
> - 給与所得控除の最低額: 55万円 → **65万円**
> - 配偶者控除・扶養控除の対象となる親族の合計所得要件: 48万円以下 → **58万円以下**
> - 19〜23歳の親族の所得が58万円超123万円以下でも段階的に控除できる**特定親族特別控除**の創設
>
> 古いテキスト・過去問の解説は48万円/55万円のままなので注意。

## 頻出論点まとめ(過去10年の出題傾向)

### ★★★ ほぼ毎回出題
1. **所得税の仕組み**
   - 暦年単位・申告納税方式。非課税所得: 通勤手当(月15万円まで)、遺族年金・障害年金、雇用保険の給付、身体の傷害に基因する保険金・損害賠償金など。
   - 総合課税と分離課税(申告分離: 土地建物・株式の譲渡、退職所得など/源泉分離: 預貯金利子など)。
2. **10種類の所得**(毎回2〜3問)
   - **給与所得**=収入−給与所得控除(最低65万円)。
   - **退職所得**=(収入−退職所得控除)×**1/2**。控除額=**40万円×勤続年数(20年以下、最低80万円)+70万円×(勤続年数−20年)**。勤続年数の1年未満端数は**切上げ**。「退職所得の受給に関する申告書」提出で源泉徴収のみで完結。役員等勤続5年以下は1/2不可。
   - **一時所得**=総収入−支出した金額−**特別控除50万円**。総所得金額への算入は**その1/2**。(生命保険の満期保険金・解約返戻金、ふるさと納税の返礼品など)
   - **雑所得**: 公的年金等(公的年金等控除、65歳以上は最低110万円)とその他(原稿料、外貨預金の為替差益など)。
   - **不動産所得**: 地代・家賃・礼金・更新料(**敷金のうち返還を要しない部分は収入**、返還するものは収入でない)。事業的規模(5棟10室)でも不動産所得。
   - **事業所得**=総収入−必要経費。
3. **損益通算**(超頻出)
   - 通算できる損失は「**不・事・山・譲**」(不動産・事業・山林・譲渡所得)のみ。
   - ただし、**不動産所得の損失のうち土地取得のための借入金利子**は通算不可。
   - **土地建物の譲渡損失**(居住用の特例を除く)、**株式の譲渡損失**(申告分離内でのみ通算可)、**生活に通常必要でない資産(別荘・ゴルフ会員権等)の譲渡損失**は通算不可。
4. **所得控除**
   - **医療費控除**=(支払医療費−保険金等で補填される金額)−**10万円**(総所得200万円未満は総所得×5%)。限度200万円。人間ドックは**重大な疾病が発見され治療した場合は対象**。美容整形・自家用車での通院ガソリン代は対象外(公共交通機関の通院費は対象)。セルフメディケーション税制(12,000円超、限度88,000円)と選択適用。
   - **配偶者控除**: 納税者本人の合計所得**1,000万円以下**+配偶者の合計所得**58万円以下**で最高38万円(70歳以上の老人控除対象配偶者は最高48万円)。
   - **扶養控除**: 一般(16歳以上)38万円/**特定扶養親族(19歳以上23歳未満)63万円**/老人(70歳以上)48万円(同居老親等58万円)。**16歳未満は対象外**。
   - 社会保険料控除(生計一親族の分も全額)、小規模企業共済等掛金控除(iDeCo)、地震保険料控除(最高5万円)。
5. **税額控除**
   - **住宅借入金等特別控除(住宅ローン控除)**: 年末残高×**0.7%**。新築(認定住宅等)は原則**13年**、中古は10年。合計所得**2,000万円以下**、床面積**50㎡以上**(新築で合計所得1,000万円以下なら40㎡以上)。**給与所得者は初年度のみ確定申告が必要、2年目以降は年末調整で可**。繰上げ返済で返済期間が当初借入日から10年未満になると適用不可。
   - **配当控除**: 総合課税を選択した配当所得(J-REITの分配金・NISA・申告不要選択分は対象外)。課税総所得1,000万円以下の部分は配当所得×10%。
6. **確定申告**
   - 期間: 翌年**2月16日〜3月15日**。
   - 給与所得者でも申告が必要: **給与収入2,000万円超**/給与・退職所得以外の所得が**20万円超**/2ヶ所以上から給与など。
   - **年末調整では受けられない控除: 医療費控除・寄附金控除(ワンストップ特例を除く)・雑損控除** → 確定申告が必要。
7. **青色申告**(超頻出)
   - 対象: **不動産所得・事業所得・山林所得**がある人。
   - 承認申請: 原則その年の**3月15日まで**(1月16日以後開業なら開業から**2ヶ月以内**)。
   - **青色申告特別控除**: 事業的規模の不動産所得または事業所得+正規の簿記+貸借対照表等添付+期限内申告→**55万円**、さらに**e-Tax申告または電子帳簿保存で65万円**。それ以外は10万円。
   - 特典: **純損失の3年間繰越控除**・繰戻還付、**青色事業専従者給与**(事前届出、全額必要経費。ただし配偶者控除等との併用不可)。
8. **法人税**
   - 各事業年度の所得に法人税率**23.2%**(中小法人は所得800万円以下の部分**15%**)。
   - 益金不算入(受取配当等)・損金不算入(法人税・住民税、罰金、役員給与のうち定期同額等に該当しないもの)。
   - **交際費**: 中小法人は「年800万円まで全額」or「接待飲食費の50%」を選択して損金算入。**1人あたり1万円以下の飲食費は交際費から除外**(全額損金)。
   - 会社・役員間の取引: 会社が役員に無利息貸付→**会社側に認定利息**、役員に低額で資産譲渡→時価との差額が役員給与。
9. **消費税**
   - 課税事業者: **基準期間(前々年度)の課税売上高が1,000万円超**(または特定期間の課税売上高等が1,000万円超)。新設法人は資本金**1,000万円以上**なら設立当初から課税。
   - **簡易課税**: 基準期間の課税売上高**5,000万円以下**+事前届出。みなし仕入率で計算。2年間継続適用。
   - 土地の譲渡・貸付け(1ヶ月以上)、住宅の貸付けは**非課税**。申告期限: 法人は課税期間終了後2ヶ月以内、個人は翌年3月31日。

## 対策問題(10問)

### 問1 所得税の仕組み
所得税に関する次の記述のうち、**最も不適切**なものはどれか。

1. 所得税は、納税者本人が所得と税額を計算して申告・納付する申告納税方式を採用している。
2. 雇用保険の基本手当や遺族基礎年金は、所得税の課税対象とならない。
3. 給与所得者が受け取る通勤手当は、金額の多寡にかかわらず全額が非課税となる。
4. 預貯金の利子は、原則として源泉分離課税の対象となる。

### 問2 退職所得(計算)
勤続年数24年3ヶ月で退職し、退職金2,000万円を受け取った場合の退職所得の金額として、**最も適切**なものはどれか(障害者になったことによる退職ではなく、役員等ではない。「退職所得の受給に関する申告書」は提出済み)。

1. 425万円
2. 460万円
3. 850万円
4. 920万円

### 問3 一時所得
一時所得に関する次の記述のうち、**最も適切**なものはどれか。

1. 一時所得の金額は、総収入金額から収入を得るために支出した金額を控除して計算し、特別控除は適用されない。
2. 一時所得の金額は、その全額を総所得金額に算入する。
3. 契約者(=保険料負担者)が受け取る生命保険の満期保険金は、一時所得として総合課税の対象となる(金融類似商品に該当する場合を除く)。
4. 一時所得の金額の計算上生じた損失は、給与所得と損益通算できる。

### 問4 損益通算
所得税の損益通算に関する次の記述のうち、**最も適切**なものはどれか。

1. 不動産所得の金額の計算上生じた損失のうち、土地を取得するための借入金の利子に相当する部分は、他の所得と損益通算できない。
2. ゴルフ会員権を譲渡したことによる損失は、給与所得と損益通算できる。
3. 上場株式を譲渡したことによる損失は、不動産所得と損益通算できる。
4. 雑所得の金額の計算上生じた損失は、事業所得と損益通算できる。

### 問5 医療費控除
医療費控除に関する次の記述のうち、**最も不適切**なものはどれか。

1. 医療費控除の額は、原則として「(支払った医療費−保険金等で補填される金額)−10万円」で計算される(総所得金額等が200万円以上の場合)。
2. 人間ドックの費用は、検査の結果重大な疾病が発見され、引き続き治療を行った場合には、医療費控除の対象となる。
3. 自家用車で通院した場合のガソリン代・駐車場代は、医療費控除の対象となる。
4. 医療費控除の適用を受けるためには、給与所得者であっても確定申告をしなければならない。

### 問6 配偶者控除・扶養控除
所得控除に関する次の記述のうち、**最も不適切**なものはどれか。

1. 配偶者控除の適用を受けるためには、納税者本人の合計所得金額が1,000万円以下でなければならない。
2. 特定扶養親族(19歳以上23歳未満)に係る扶養控除の額は63万円である。
3. 16歳未満の扶養親族は、扶養控除の対象とならない。
4. 同居している70歳以上の老人扶養親族(同居老親等)に係る扶養控除の額は48万円である。

### 問7 住宅ローン控除
住宅借入金等特別控除(住宅ローン控除)に関する次の記述のうち、**最も不適切**なものはどれか。

1. 控除額は、原則として住宅ローンの年末残高(限度額あり)に0.7%を乗じて計算される。
2. 適用を受けるためには、原則として、その年分の合計所得金額が2,000万円以下でなければならない。
3. 給与所得者は、初年度から年末調整によって適用を受けることができる。
4. 繰上げ返済により、借入日から返済終了までの期間が10年未満となった場合、その後は適用を受けられない。

### 問8 確定申告
所得税の確定申告に関する次の記述のうち、**最も適切**なものはどれか。

1. 確定申告の期間は、原則として、所得が生じた年の翌年2月1日から3月15日までである。
2. 年末調整を受けた給与所得者は、給与所得・退職所得以外の所得が20万円を超える場合でも、確定申告は不要である。
3. その年中の給与収入が2,000万円を超える給与所得者は、年末調整の対象とならず、確定申告をしなければならない。
4. 医療費控除は、給与所得者であれば年末調整により適用を受けることができる。

### 問9 青色申告
青色申告に関する次の記述のうち、**最も不適切**なものはどれか。

1. 青色申告ができるのは、不動産所得・事業所得・山林所得を生ずべき業務を行う者である。
2. その年の1月16日以後に新たに開業した者が青色申告をするには、開業日から2ヶ月以内に承認申請書を提出しなければならない。
3. 青色申告者は、純損失の金額を翌年以後5年間にわたって繰り越すことができる。
4. 事業所得者が正規の簿記の原則により記帳し、貸借対照表等を添付して期限内にe-Taxで申告した場合、最高65万円の青色申告特別控除を受けられる。

### 問10 消費税
消費税に関する次の記述のうち、**最も不適切**なものはどれか。

1. 基準期間の課税売上高が1,000万円を超える事業者は、消費税の課税事業者となる。
2. 簡易課税制度を選択できるのは、基準期間の課税売上高が5,000万円以下の事業者である。
3. 土地の譲渡は、消費税の課税取引に該当しない。
4. 新たに設立された法人は、資本金の額にかかわらず、設立後2年間は必ず免税事業者となる。

## 解答・解説

**問1 正解 3** — 通勤手当の非課税は**月15万円まで**。「金額の多寡にかかわらず」が誤り。

**問2 正解 1** — 勤続年数は1年未満の端数**切上げ**で25年。退職所得控除=40万×20年+70万×(25−20)=800万+350万=**1,150万円**。退職所得=(2,000万−1,150万)×**1/2**=**425万円**。「端数切上げ」「×1/2」「20年の境目で40万→70万」の3点がお約束の引っかけどころ(3の850万円は×1/2忘れの誤答)。

**問3 正解 3** — 1: 特別控除50万円がある。2: 総所得算入は**1/2**。4: 一時所得の損失は損益通算不可(なかったものとされる)。

**問4 正解 1** — 損益通算できるのは不・事・山・譲のみ、かつ不動産所得の**土地**取得借入金利子部分は除外(建物分は通算可)。2: ゴルフ会員権は通算不可。3: 株式譲渡損は申告分離の枠内のみ。4: 雑所得の損失は通算不可。

**問5 正解 3** — 自家用車のガソリン代・駐車場代は対象外(電車・バス等の通院費は対象)。

**問6 正解 4** — 同居老親等は**58万円**(同居していない老人扶養親族が48万円)。

**問7 正解 3** — 初年度は**確定申告が必要**。2年目以降は年末調整で可。

**問8 正解 3** — 1: 2月**16日**から。2: 20万円超なら申告必要。4: 医療費控除は年末調整不可。

**問9 正解 3** — 純損失の繰越控除は**3年間**(法人の欠損金10年と混同させる引っかけ)。

**問10 正解 4** — 資本金**1,000万円以上**の新設法人は設立当初から課税事業者。

> **メモ**: 問2のように退職所得の計算は学科・実技とも頻出。「勤続20年超: 800万円+70万円×(勤続年数−20年)」を体で覚えること。
