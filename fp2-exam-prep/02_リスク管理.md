# 第2分野 リスク管理(学科 問11〜20)

## 頻出論点まとめ(過去10年の出題傾向)

### ★★★ ほぼ毎回出題
1. **保険契約者保護の仕組み**
   - 生命保険契約者保護機構: 破綻時、**責任準備金等の90%**まで補償(高予定利率契約を除く)。国内で営業するすべての生保(かんぽ含む)が加入。**少額短期保険業者・共済は対象外**。
   - 損害保険契約者保護機構: **自賠責保険・地震保険は100%**、自動車保険等は破綻後3ヶ月以内の保険金100%(その後80%)。
   - クーリング・オフ: 契約申込日または申込撤回等に関する書面受領日のいずれか遅い日から**8日以内**に書面または電磁的記録で撤回可。
2. **生命保険の仕組み・契約手続き**
   - 保険料は**予定死亡率・予定利率・予定事業費率**の3つの予定基礎率で計算。予定利率が**高い**ほど保険料は**安い**。
   - 告知義務は**質問応答義務**(聞かれたことに答える)。告知受領権は保険会社・診査医にあり、**営業職員にはない**。
   - 責任開始日: **申込み・告知・第1回保険料払込み**の3つがそろった時(承諾を前提)。
   - 失効と復活: 復活時は延滞保険料をまとめて払込み、**告知(診査)が再度必要**。保険料は失効前と同じ。
   - 自動振替貸付・契約者貸付は**解約返戻金の範囲内**、利息が付く。
3. **生命保険商品**
   - 収入保障保険: 死亡時から満期まで年金形式で支払い。**一時金受取りは年金受取総額より少ない**。保険料は同保障の定期保険より安い。
   - 変額保険: 特別勘定で運用。**死亡保険金には基本保険金額の最低保証がある**が、解約返戻金・満期保険金に最低保証はない。
   - 外貨建て保険: 為替リスクあり。円換算特約を付けても**為替リスクは回避できない**。
   - 個人年金: 確定年金(生死問わず一定期間)・終身年金(同条件なら**女性の方が保険料が高い**)・保証期間付終身年金。
4. **生命保険と税金**
   - 生命保険料控除(2012年以降契約): **一般・介護医療・個人年金**の3区分、所得税各**4万円**(計12万円)、住民税各2.8万円(計7万円)。
   - 個人年金保険料税制適格特約の要件: 受取人が本人または配偶者/払込期間**10年以上**/60歳以降・受取期間10年以上の確定・終身年金。
   - 死亡保険金の課税(超頻出):

     | 契約者(保険料負担者) | 被保険者 | 受取人 | 課税 |
     |---|---|---|---|
     | A | A | B | **相続税**(受取人が相続人なら500万×法定相続人非課税) |
     | A | B | A | **所得税(一時所得)** |
     | A | B | C | **贈与税** |
   - 満期保険金: 契約者=受取人→一時所得。**一時払養老保険等を5年以内に受け取ると金融類似商品として20.315%源泉分離課税**。
   - **入院給付金・手術給付金・通院給付金等、身体の傷害に基因して支払われる給付金は非課税**。リビング・ニーズ特約保険金も非課税。
5. **法人契約の経理処理**(2019年7月以降契約の定期保険等)
   - 最高解約返戻率**50%以下→全額損金**/50%超70%以下→当初4割資産計上/70%超85%以下→当初6割資産計上/85%超→支払保険料×最高解約返戻率×90%を資産計上。
   - 養老保険の**ハーフタックスプラン**: 死亡保険金受取人=従業員の遺族、満期保険金受取人=法人、全従業員加入 → 保険料の**1/2損金(福利厚生費)・1/2資産計上**。
6. **地震保険**
   - 単独では契約できず**火災保険に付帯**。保険金額は主契約の**30〜50%**、**建物5,000万円・家財1,000万円**が上限。
   - 損害区分は4区分: **全損100%・大半損60%・小半損30%・一部損5%**。
   - 割引制度4種(建築年・耐震等級・免震建築物・耐震診断)は**重複適用不可**、最大50%。保険料は構造と所在地で決まり、**保険会社による差はない**。
   - 地震保険料控除: 所得税**全額(最高5万円)**・住民税1/2(最高2.5万円)。
7. **自動車保険**
   - 自賠責: 対人賠償のみ。**死亡3,000万円・後遺障害最高4,000万円・傷害120万円**(被害者1人あたり)。
   - 任意保険: 人身傷害補償保険は**自分の過失分も含めて**示談を待たず支払われる。対人・対物賠償は**被保険者の家族(父母・配偶者・子)への賠償は対象外**。
8. **傷害保険・賠償責任保険**
   - 普通傷害保険: 国内外・業務中も対象。**細菌性食中毒・地震・噴火・津波は対象外**(特約で付帯可)。
   - 家族傷害保険: 事故発生時点の続柄で判定(本人・配偶者・生計を共にする同居親族・別居の未婚の子)。
   - 国内旅行傷害保険: **食中毒は対象**、地震・噴火・津波は対象外。海外旅行(傷害)保険: **食中毒も地震等も対象**、自宅を出てから帰宅するまで(国内移動中も)対象。
   - 個人賠償責任保険: 日常生活の賠償事故(自転車事故、飼い犬の咬傷、買い物中の商品破損等)。**業務中の事故・自動車事故・預かり物(受託物)は対象外**。生計を共にする家族も被保険者。
9. **第三分野・その他**
   - がん保険: 契約後**90日(3ヶ月)程度の免責期間**あり。入院給付金に支払日数の限度なし(一般的)。
   - 先進医療特約: **療養を受けた時点**で先進医療と定められている治療が対象。
   - 所得補償保険: 病気・ケガで就業不能となった場合の所得を補償(入院中でなく自宅療養でも対象)。
   - 火災保険: **住宅火災保険は水災補償なし、住宅総合保険は水災補償あり**。失火責任法により、軽過失の失火で隣家を焼いても賠償責任を負わない(借家人は家主に対し債務不履行責任を負う)。

## 対策問題(10問)

### 問1 契約者保護
生命保険契約者保護機構に関する次の記述のうち、**最も適切**なものはどれか。

1. 国内で事業を行う生命保険会社が破綻した場合、原則として、破綻時点の死亡保険金額の90%まで補償される。
2. 生命保険契約者保護機構による補償の対象は、原則として、破綻時点の責任準備金等の90%である。
3. 少額短期保険業者が引き受けた保険契約も、生命保険契約者保護機構の補償の対象となる。
4. 銀行の窓口で加入した生命保険契約は、預金保険機構による保護の対象となる。

### 問2 保険料の仕組み・告知
生命保険の一般的な仕組みに関する次の記述のうち、**最も不適切**なものはどれか。

1. 保険料は、予定死亡率・予定利率・予定事業費率の3つの予定基礎率に基づいて計算される。
2. 他の条件が同一であれば、予定利率が高いほど保険料は高くなる。
3. 告知義務者は、保険会社が告知を求めた事項について答える義務(質問応答義務)を負う。
4. 生命保険募集人(営業職員)には告知受領権がなく、営業職員に口頭で伝えただけでは告知したことにならない。

### 問3 生命保険商品
生命保険商品に関する次の記述のうち、**最も不適切**なものはどれか。

1. 収入保障保険の死亡保険金を一時金で受け取る場合の金額は、年金形式で受け取る場合の受取総額よりも少なくなる。
2. 変額保険(終身型)では、死亡保険金について基本保険金額が最低保証されている。
3. 外貨建て終身保険は、円換算支払特約を付加することで、為替変動リスクを回避することができる。
4. 定期保険特約付終身保険(更新型)では、定期保険特約を同額で自動更新すると、更新後の保険料は通常、更新前より高くなる。

### 問4 個人年金保険
個人年金保険に関する次の記述のうち、**最も不適切**なものはどれか。

1. 確定年金では、年金受取期間中に被保険者が死亡した場合でも、残りの期間の年金または一時金が遺族に支払われる。
2. 終身年金では、他の条件が同一であれば、保険料は被保険者が女性の方が男性よりも高くなる。
3. 個人年金保険料税制適格特約を付加するためには、年金受取人が契約者またはその配偶者で、かつ被保険者と同一であることが必要である。
4. 保証期間付終身年金では、保証期間中に被保険者が死亡した場合、年金の支払いは直ちに終了する。

### 問5 生命保険と税金(死亡保険金)
契約者(=保険料負担者)が夫、被保険者が妻、死亡保険金受取人が子である生命保険契約において、妻の死亡により子が受け取る死亡保険金の課税関係として、**最も適切**なものはどれか。

1. 相続税の課税対象となる。
2. 贈与税の課税対象となる。
3. 所得税(一時所得)の課税対象となる。
4. 非課税となる。

### 問6 生命保険料控除
2012年1月1日以後に締結した生命保険契約の生命保険料控除に関する次の記述のうち、**最も不適切**なものはどれか。

1. 控除は「一般の生命保険料」「介護医療保険料」「個人年金保険料」の3区分である。
2. 所得税における控除限度額は、各区分それぞれ4万円、合計12万円である。
3. 入院給付金のある医療保険の保険料は、介護医療保険料控除の対象となる。
4. 傷害特約や災害割増特約の保険料も、一般の生命保険料控除の対象となる。

### 問7 法人契約の経理処理
法人を契約者(=保険料負担者)とする生命保険の経理処理に関する次の記述のうち、**最も不適切**なものはどれか。なお、いずれも2019年7月8日以後に締結した契約とする。

1. 被保険者が役員、死亡保険金受取人が法人である最高解約返戻率40%の定期保険の保険料は、全額を損金の額に算入できる。
2. 被保険者が全従業員、死亡保険金受取人が従業員の遺族、満期保険金受取人が法人である養老保険の保険料は、2分の1を福利厚生費として損金算入できる。
3. 法人が受け取った死亡保険金は、その全額を益金の額に算入する(資産計上額がある場合は取り崩す)。
4. 最高解約返戻率85%超の定期保険の保険料は、契約当初から全額を損金の額に算入できる。

### 問8 地震保険
地震保険に関する次の記述のうち、**最も適切**なものはどれか。

1. 地震保険は、火災保険とは独立して単独で契約することができる。
2. 地震保険の保険金額は、主契約である火災保険の保険金額の30%から50%の範囲内で、建物5,000万円・家財1,000万円が上限である。
3. 地震保険の損害区分は「全損」「半損」「一部損」の3区分である。
4. 地震保険の建築年割引と耐震等級割引は、重複して適用を受けることができる。

### 問9 自動車保険
自動車保険に関する次の記述のうち、**最も不適切**なものはどれか。

1. 自賠責保険の支払限度額は、被害者1人につき、死亡3,000万円、傷害120万円である。
2. 自賠責保険は対人賠償事故のみを対象とし、対物賠償事故は対象とならない。
3. 人身傷害補償保険では、被保険者自身の過失割合に相当する部分を差し引いた損害額が支払われる。
4. 任意の対人賠償保険では、運転者の父母・配偶者・子に対する賠償は補償の対象とならない。

### 問10 傷害保険・賠償責任保険
傷害保険および賠償責任保険に関する次の記述のうち、**最も適切**なものはどれか。

1. 普通傷害保険では、細菌性食中毒による損害は特約がなくても補償の対象となる。
2. 国内旅行傷害保険では、地震・噴火・津波による傷害も補償の対象となる。
3. 海外旅行(傷害)保険では、海外旅行のために自宅を出発してから帰宅するまでの間の傷害が対象となり、国内移動中の事故も補償される。
4. 個人賠償責任保険では、業務中に顧客の物を壊した場合の賠償責任も補償の対象となる。

## 解答・解説

**問1 正解 2** — 補償は保険金額ではなく**責任準備金等の90%**(1が誤りの典型パターン)。3: 少額短期保険業者は対象外。4: 銀行窓販でも保護するのは生命保険契約者保護機構(預金保険ではない)。

**問2 正解 2** — 予定利率が高い=運用収益を多く見込める→保険料は**安く**なる。

**問3 正解 3** — 円換算特約は支払い等を円貨で行うだけで、**為替リスクそのものは回避できない**。

**問4 正解 4** — 保証期間付終身年金は、保証期間内の死亡なら**残存保証期間分が遺族に支払われる**。2は正しい(女性は長寿のため終身年金の保険料が高い)。

**問5 正解 2** — 契約者・被保険者・受取人がすべて異なる三者パターン→**贈与税**。表の3パターンは学科・実技とも超頻出。

**問6 正解 4** — 傷害特約・災害割増特約など**身体の傷害のみに基因して支払われる特約の保険料は控除対象外**。

**問7 正解 4** — 最高解約返戻率85%超は「支払保険料×最高解約返戻率×90%」を当初資産計上するルールで、全額損金は不可。1(50%以下→全損)、2(ハーフタックスプラン)、3は正しい。

**問8 正解 2** — 1: 単独契約不可。3: 全損・大半損・小半損・一部損の**4区分**。4: 割引は重複適用**不可**。

**問9 正解 3** — 人身傷害補償保険は**自分の過失分も含めて**実際の損害額が支払われるのが特徴。

**問10 正解 3** — 1: 普通傷害保険は細菌性食中毒対象外(特約要)。2: 国内旅行傷害保険は食中毒○だが地震等×。4: 個人賠償責任保険は業務中の事故対象外。
