# 第3分野 金融資産運用(学科 問21〜30)

## 頻出論点まとめ(過去10年の出題傾向)

### ★★★ ほぼ毎回出題
1. **経済・金融指標**
   - GDP: **内閣府**が四半期ごとに公表。支出側の最大項目は**民間最終消費支出(5割超)**。
   - 景気動向指数: 内閣府が毎月公表。**CIは景気変動の大きさ・テンポ(量感)**、**DIは波及度(方向性)**を測る。現在は**CI中心**。一致系列に「鉱工業生産指数」、先行系列に「新規求人数」「東証株価指数」、遅行系列に「完全失業率」「消費者物価指数」。
   - 日銀短観: **日本銀行が年4回**、企業に直接アンケート。**業況判断DI=「良い」−「悪い」の回答割合**。
   - マネーストック: 通貨保有主体(**国・金融機関を除く**経済主体)が保有する通貨量。日銀が毎月公表。
   - 消費者物価指数(CPI): **総務省**が毎月公表。
2. **金利・金融政策**
   - 物価上昇→金利上昇、円安→輸入物価上昇→金利上昇要因、景気拡大→金利上昇。
   - 日銀の公開市場操作: **買いオペ→資金供給→金利低下**、売りオペ→資金吸収→金利上昇。
3. **セーフティネット**
   - 預金保険: 1金融機関1預金者あたり**元本1,000万円+利息**。**決済用預金(無利息・要求払い・決済サービス)は全額保護**。**外貨預金・譲渡性預金は対象外**。
   - 日本投資者保護基金: 証券会社破綻+分別管理義務違反時に**1,000万円**まで補償。銀行で購入した投資信託は**対象外**(ただし分別管理はされている)。
4. **債券**
   - 利回り計算(応募者・最終・所有期間): 「(クーポン+差益÷年数)÷購入価格×100」の型。
   - **市場金利上昇→債券価格下落(利回り上昇)**。残存期間が**長い**ほど・表面利率が**低い**ほど価格変動幅は**大きい**(デュレーション大)。
   - 格付け: **BBB以上=投資適格**、BB以下=投機的(ハイイールド)。格付けが低いほど利回りは高く、価格は安い。
   - 個人向け国債: **変動10年・固定5年・固定3年**、**最低金利0.05%保証**、毎月発行、購入単位1万円、**発行後1年経過で中途換金可**(直前2回分の利子相当額×0.79685が差し引かれる)。
5. **株式**
   - 投資指標(計算問題頻出):
     - **PER(倍)=株価÷1株当たり純利益(EPS)** — 低いほど割安
     - **PBR(倍)=株価÷1株当たり純資産(BPS)** — 1倍で解散価値
     - **ROE(%)=当期純利益÷自己資本×100**
     - **配当利回り(%)=1株当たり配当÷株価×100**
     - **配当性向(%)=配当金総額÷当期純利益×100**
   - 売買ルール: 受渡しは**約定日から起算して3営業日目(T+2)**。配当・株主優待を受けるには**権利確定日の2営業日前(権利付き最終日)までに約定**が必要。
   - 注文: 成行注文は指値注文に**優先**。指値は価格優先(買いは高い方・売りは安い方)・時間優先。
   - 日経平均株価=225銘柄の**株価平均型**(株価水準の高い銘柄の影響大)、TOPIX=**時価総額加重型**(時価総額の大きい銘柄の影響大)。
6. **投資信託**
   - コスト: 購入時手数料(ノーロードあり)/**運用管理費用(信託報酬)=保有中、信託財産から日々差し引き**/信託財産留保額=換金時(かからないものもある)。
   - 運用手法: **パッシブ運用=指数連動**、アクティブ運用。**トップダウン=マクロ経済分析から**、ボトムアップ=個別企業分析から。**グロース=成長性重視**、**バリュー=割安株重視**。
   - ETF: 上場投信。**指値・成行注文、信用取引も可**。運用管理費用は一般に非上場投信より低い。
   - J-REIT: 上場不動産投信。分配金は配当所得だが**配当控除の適用なし**。
7. **外貨建て商品**
   - **TTS=顧客が円→外貨(預入時)**、**TTB=顧客が外貨→円(払戻時)**。TTM±為替手数料。
   - 為替差益: 預入時に為替予約なし→**雑所得(総合課税)**。外貨預金の利子は源泉分離20.315%。**外貨預金は預金保険の対象外**。
8. **ポートフォリオ理論**
   - ポートフォリオの期待収益率=各資産の期待収益率の**加重平均**。
   - 相関係数: **−1〜+1**。**−1のとき分散投資によるリスク低減効果は最大**。+1のときは低減効果なし。
   - **シャープレシオ=(ポートフォリオの収益率−無リスク資産利子率)÷標準偏差** — 大きいほど効率的(計算問題頻出)。
   - システマティック・リスク(市場リスク)は分散投資でも**消せない**。
9. **デリバティブ**
   - コール=**買う権利**、プット=**売る権利**。オプションの買い手の損失は**プレミアムに限定**、売り手の損失は限定されない。
   - 満期までの期間が**長い**ほど、ボラティリティが**大きい**ほど、プレミアム(コール・プットとも)は**高い**。
10. **NISA(2024年〜)**
    - **つみたて投資枠120万円/年・成長投資枠240万円/年、併用可**。非課税保有限度額**1,800万円(うち成長投資枠1,200万円)**。非課税期間**無期限**。
    - 売却すると**翌年以降、簿価分の枠が復活**。対象は18歳以上。
    - NISA口座内の損失は**他口座の利益と損益通算できず、繰越控除も不可**。つみたて投資枠の対象は**長期・積立・分散に適した一定の投資信託等**(個別株は成長投資枠のみ)。
11. **関連法規**
    - 金融サービス提供法: 重要事項の説明義務違反→**損害賠償責任**。
    - 消費者契約法: 誤認等による契約の**取消し**。
    - 金融商品取引法: **適合性の原則**(知識・経験・財産・目的に照らして不適当な勧誘の禁止)、断定的判断の提供の禁止。

## 対策問題(10問)

### 問1 経済指標
経済指標に関する次の記述のうち、**最も不適切**なものはどれか。

1. 国内総生産(GDP)は内閣府が公表しており、支出側で最も大きな割合を占めるのは民間最終消費支出である。
2. 景気動向指数のCI(コンポジット・インデックス)は、主として景気変動の大きさやテンポ(量感)を測定するものである。
3. 日銀短観の業況判断DIは、業況が「良い」と回答した企業の割合から「悪い」と回答した企業の割合を差し引いて算出される。
4. マネーストック統計は、金融機関や国を含むすべての経済主体が保有する通貨量の残高を集計したものである。

### 問2 預金保険制度
預金保険制度に関する次の記述のうち、**最も適切**なものはどれか。

1. 外貨預金は、預金保険制度による保護の対象となる。
2. 決済用預金は、預入額にかかわらず全額が保護される。
3. 1金融機関につき預金者1人あたり、元本1,500万円までとその利息が保護される。
4. 銀行で購入した投資信託は、預金保険制度による保護の対象となる。

### 問3 債券の利回り(計算)
表面利率1.0%、残存期間5年の固定利付債券を額面100円あたり102円で購入し、償還まで保有した場合の最終利回り(単利・年率)として最も適切なものはどれか。なお、税金等は考慮せず、答は表示単位の小数点以下第3位を四捨五入している。

1. 0.20%
2. 0.59%
3. 0.98%
4. 1.37%

### 問4 債券のリスク
債券投資に関する次の記述のうち、**最も不適切**なものはどれか。

1. 市場金利が上昇すると、既発行の固定利付債券の価格は下落する。
2. 他の条件が同一であれば、表面利率が高い債券ほど、金利変動に対する価格の変動幅は大きい。
3. 格付けがBBB(トリプルB)以上の債券は、一般に投資適格債とされる。
4. 個人向け国債は、発行後1年を経過すれば、中途換金することができる。

### 問5 株式の投資指標(計算)
次の資料の株式のPERとPBRの組合せとして、**最も適切**なものはどれか。

- 株価: 1,200円/1株当たり純利益: 80円/1株当たり純資産: 800円

1. PER 15倍・PBR 1.5倍
2. PER 15倍・PBR 0.67倍
3. PER 6.7倍・PBR 1.5倍
4. PER 1.5倍・PBR 15倍

### 問6 投資信託
投資信託に関する次の記述のうち、**最も不適切**なものはどれか。

1. 運用管理費用(信託報酬)は、投資信託を保有している間、信託財産から日々差し引かれる。
2. マクロ経済の動向分析から国別・業種別の配分を決め、その後個別銘柄を選定する手法をボトムアップ・アプローチという。
3. ベンチマークとする指数に連動する運用成果を目指す手法をパッシブ運用という。
4. ETF(上場投資信託)は、上場株式と同様に、指値注文や成行注文により売買することができる。

### 問7 外貨預金
外貨建て金融商品に関する次の記述のうち、**最も適切**なものはどれか。

1. 顧客が円を外貨に換えて外貨預金に預け入れる際に適用される為替レートは、TTBである。
2. 外貨預金は、預金保険制度による保護の対象となる。
3. 国内の銀行に預け入れた外貨定期預金の為替差益(預入時に為替予約なし)は、雑所得として総合課税の対象となる。
4. 為替レートが預入時より円高になると、円換算の利回りは上昇する。

### 問8 ポートフォリオ理論
ポートフォリオ理論に関する次の記述のうち、**最も不適切**なものはどれか。

1. ポートフォリオの期待収益率は、組み入れた各資産の期待収益率を組入比率で加重平均した値となる。
2. 2資産間の相関係数が+1のとき、分散投資によるリスク低減効果は最大となる。
3. シャープレシオは、超過収益率(収益率−無リスク資産利子率)を標準偏差で除して求め、数値が大きいほど効率的な運用といえる。
4. 市場全体の動きに起因するシステマティック・リスクは、分散投資によっても消去できない。

### 問9 オプション取引
オプション取引に関する次の記述のうち、**最も適切**なものはどれか。

1. 原資産を将来の一定期日に一定の価格で「売る権利」をコール・オプションという。
2. オプションの売り手の損失は、受け取ったプレミアムの額に限定される。
3. 他の条件が同一であれば、満期までの残存期間が長いほど、プレミアムは高くなる。
4. オプションの買い手は、権利行使義務を負う。

### 問10 NISA
2024年以降のNISA制度に関する次の記述のうち、**最も不適切**なものはどれか。

1. つみたて投資枠の年間投資枠は120万円、成長投資枠の年間投資枠は240万円であり、両枠は併用できる。
2. 非課税保有限度額は総枠1,800万円であり、このうち成長投資枠は1,200万円が上限である。
3. NISA口座で生じた譲渡損失は、特定口座で生じた譲渡益と損益通算することができる。
4. NISA口座内の商品を売却した場合、その簿価残高分の非課税枠を翌年以降再利用できる。

## 解答・解説

**問1 正解 4** — マネーストックの通貨保有主体から**国・金融機関は除かれる**。

**問2 正解 2** — 決済用預金(無利息・要求払い・決済サービス提供)は全額保護。1: 外貨預金は対象外。3: 1,000万円+利息。4: 投信は預金保険の対象外。

**問3 正解 2** — 最終利回り=(1.0+(100−102)÷5)÷102×100=(1.0−0.4)÷102×100≒**0.588→0.59%**。オーバーパー購入なので表面利率より低くなる、という感覚チェックも有効。

**問4 正解 2** — 表面利率が**低い**ほど(クーポン収入が少なく回収が遅いため)価格変動幅は大きい。

**問5 正解 1** — PER=1,200÷80=**15倍**、PBR=1,200÷800=**1.5倍**。

**問6 正解 2** — マクロから入るのは**トップダウン**・アプローチ。ボトムアップは個別企業分析から積み上げる手法。

**問7 正解 3** — 1: 預入時はTTS(払戻時がTTB)。2: 外貨預金は預金保険対象外。4: 円高は為替差損→利回り低下。

**問8 正解 2** — リスク低減効果が最大になるのは相関係数**−1**のとき。+1では低減効果なし。

**問9 正解 3** — 1: 売る権利はプット。2: 損失限定はプレミアムを支払う**買い手**(売り手は損失限定されない)。4: 買い手は権利を持つが行使の義務はない。

**問10 正解 3** — NISA口座の損失は**なかったものとされ**、損益通算・繰越控除とも不可。
