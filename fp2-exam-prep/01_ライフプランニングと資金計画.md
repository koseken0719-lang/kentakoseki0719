# 第1分野 ライフプランニングと資金計画(学科 問1〜10)

## 頻出論点まとめ(過去10年の出題傾向)

### ★★★ ほぼ毎回出題
1. **FPと関連法規(コンプライアンス)** — 学科第1問の定番
   - 税理士資格のないFPは、無償であっても**個別具体的な税務相談・税務書類の作成は不可**。一般的・仮定の事例に基づく説明はOK。
   - 弁護士資格のないFPは、具体的な法律判断・法律事務は不可。**任意後見契約の受任者になることは資格不要で可**。
   - 社会保険労務士資格のないFPは、年金請求書類の作成代行は不可。**公的年金の受給見込み額の試算・制度説明はOK**。
   - 保険募集人登録のないFPは、保険の募集・勧誘は不可。**必要保障額の試算、保険商品の一般的説明はOK**。
   - 投資助言・代理業の登録のないFPは、個別銘柄の投資判断の助言は不可。**新聞・公表資料による一般的な情報提供はOK**。
2. **6つの係数**(学科・実技とも頻出)

   | 係数 | 使う場面 |
   |---|---|
   | 終価係数 | 今ある額を複利運用→**将来いくら**になるか |
   | 現価係数 | 将来の目標額のために**今いくら**必要か |
   | 年金終価係数 | 毎年の積立→将来の**合計額** |
   | 減債基金係数 | 将来の目標額のために**毎年いくら積み立てる**か |
   | 年金現価係数 | 毎年○円受け取るために**今いくら**必要か |
   | 資本回収係数 | 今ある額を取り崩し→**毎年いくら受け取れる**か(借入の毎年返済額も) |

3. **公的医療保険**
   - 傷病手当金: 連続3日間の休業(待期)の後、**4日目から通算1年6ヶ月**。支給額は支給開始日以前12ヶ月の各標準報酬月額の平均÷30の**3分の2**。
   - 高額療養費: 自己負担限度額を超えた分が支給(70歳未満・標準報酬月額28〜50万円: 80,100円+(医療費−267,000円)×1%)。**差額ベッド代・食事代・先進医療の技術料は対象外**。
   - 任意継続被保険者: 資格喪失日の前日まで**継続2ヶ月以上**の被保険者期間、喪失日から**20日以内**に申請、**最長2年間**、保険料は**全額自己負担**。
   - 後期高齢者医療制度: **75歳以上**(一定の障害は65歳以上)、自己負担は原則1割(一定以上所得2割、現役並み3割)。
4. **公的介護保険**
   - 第1号被保険者: **65歳以上**、原因を問わず要介護・要支援認定で利用可。
   - 第2号被保険者: **40〜64歳**の医療保険加入者、**特定疾病**(末期がん・初老期認知症・脳血管疾患など)による場合のみ。
   - 認定は**市町村(特別区)**が行う。自己負担は原則**1割**(第1号は所得により2割・3割)。ケアプラン作成は自己負担なし。
5. **雇用保険**
   - 基本手当: 原則、離職前2年間に被保険者期間**12ヶ月以上**(倒産・解雇は1年間に6ヶ月)。自己都合・定年退職の所定給付日数は被保険者期間10年未満**90日**/10年以上20年未満**120日**/20年以上**150日**。自己都合は7日の待期+原則**1ヶ月**の給付制限(2025年4月から2ヶ月→1ヶ月に短縮)。
   - 育児休業給付金: 休業開始時賃金日額の**67%**(181日目からは50%)。
   - 高年齢雇用継続基本給付金: 60歳以後の賃金が60歳時点の**75%未満**に低下、最大**10%**(2025年4月から15%→10%に縮小)。
6. **公的年金(老齢給付)**
   - 老齢基礎年金: 受給資格期間**10年**、満額は保険料納付済月数480月。
   - **繰上げ: 1ヶ月あたり▲0.4%**(最大60歳、▲24%)/**繰下げ: 1ヶ月あたり+0.7%**(66歳〜75歳、最大+84%)。繰上げは基礎・厚生**同時**、繰下げは**別々に可**。
   - 付加年金: 第1号被保険者が月**400円**上乗せ納付→**200円×納付月数**が老齢基礎年金に加算。繰上げ・繰下げすると同率で増減。
   - 加給年金: 厚生年金加入**20年以上**+65歳到達時に生計維持する65歳未満の配偶者等。配偶者が65歳になると打ち切り→配偶者側に振替加算。
   - 在職老齢年金: 総報酬月額相当額+基本月額が**51万円**(2025年度)を超えると超過分の1/2支給停止。
7. **遺族年金**
   - 遺族基礎年金: **「子のある配偶者」または「子」**のみ。子=18歳到達年度末まで(障害等級1・2級は20歳未満)。
   - 遺族厚生年金: 報酬比例部分の**4分の3**。短期要件は**300月みなし**。妻が受ける場合、**40歳以上65歳未満で子のない期間は中高齢寡婦加算**。夫死亡時30歳未満で子のない妻は**5年間の有期給付**。
8. **確定拠出年金(iDeCo・企業型DC)**
   - iDeCo拠出限度額(月額): 第1号**68,000円**(国民年金基金・付加保険料と合算)/会社員(企業年金なし)**23,000円**/第3号**23,000円**。
   - 掛金は**全額が小規模企業共済等掛金控除**。老齢給付は一時金なら**退職所得**、年金なら**雑所得(公的年金等控除)**。
   - 老齢給付金の受給開始は**60〜75歳**の間で選択。通算加入者等期間10年未満は60歳から受給不可(段階的に引上げ)。
9. **教育資金**
   - 国の教育一般貸付(日本政策金融公庫): 融資限度**350万円**(自宅外通学・海外留学等は**450万円**)、固定金利、返済最長18年、**保護者の所得制限あり**。入学金・授業料のほか受験費用・下宿費用等も対象。
   - 日本学生支援機構(JASSO): **第一種(無利息)・第二種(利息付)**、いずれも学生本人が借りて**返還義務あり**。給付型奨学金もある。両者は**併用可**。
10. **住宅ローン**
    - フラット35: **全期間固定金利**、金利は**融資実行時点**・取扱金融機関ごとに異なる。融資限度**8,000万円**、融資率9割超は金利が高くなる。繰上げ返済手数料**無料**(窓口100万円以上、ネット10万円以上から)。保証人・保証料不要。
    - 繰上げ返済: **期間短縮型の方が返済額軽減型より利息軽減効果が大きい**(同時期・同額なら)。

### ★★ よく出る

- 国民年金の保険料免除・学生納付特例(追納は**10年以内**)、産前産後免除(納付済扱い)

## 対策問題(10問)

### 問1 FPと関連法規
ファイナンシャル・プランナーの行為に関する次の記述のうち、**最も不適切**なものはどれか。

1. 税理士資格を有しないFPが、顧客から相談料を受け取らずに、顧客の確定申告書を作成した。
2. 社会保険労務士資格を有しないFPが、顧客の「ねんきん定期便」をもとに公的年金の受給見込み額を試算した。
3. 弁護士資格を有しないFPが、顧客と任意後見契約を締結し、任意後見受任者となった。
4. 生命保険募集人の登録を受けていないFPが、顧客のライフプランに基づき必要保障額を試算した。

### 問2 6つの係数
元金1,500万円を年利2%で複利運用しながら20年間にわたって毎年均等に取り崩す場合、毎年の受取額を求める際に使用する係数として、**最も適切**なものはどれか。

1. 減債基金係数
2. 資本回収係数
3. 年金現価係数
4. 現価係数

### 問3 傷病手当金
全国健康保険協会管掌健康保険(協会けんぽ)の傷病手当金に関する次の記述のうち、**最も不適切**なものはどれか。

1. 傷病手当金は、業務外の病気やケガの療養のため労務に服することができない場合に支給される。
2. 傷病手当金は、労務に服することができなくなった日から連続して3日間の待期期間の後、4日目以降の労務に服することができない日から支給される。
3. 傷病手当金の額は、原則として、支給開始日以前12ヶ月間の各標準報酬月額の平均額の30分の1に相当する額の3分の2である(1日あたり)。
4. 傷病手当金の支給期間は、支給開始日から連続して最長1年6ヶ月である。

### 問4 公的介護保険
公的介護保険に関する次の記述のうち、**最も適切**なものはどれか。

1. 第2号被保険者は、要介護状態となった原因を問わず、保険給付を受けることができる。
2. 要介護認定・要支援認定は、都道府県が行う。
3. 第1号被保険者の介護サービス利用時の自己負担割合は、所得にかかわらず一律1割である。
4. 第2号被保険者は、40歳以上65歳未満の公的医療保険加入者である。

### 問5 雇用保険
雇用保険に関する次の記述のうち、**最も不適切**なものはどれか。

1. 基本手当を受給するためには、原則として、離職の日以前2年間に被保険者期間が通算12ヶ月以上あることが必要である。
2. 自己都合退職の場合の基本手当の所定給付日数は、算定基礎期間20年以上で最長330日である。
3. 育児休業給付金の額は、休業開始日から180日までは、原則として休業開始時賃金日額×支給日数の67%相当額である。
4. 定年退職者も、失業の状態にあり求職の申込みを行えば、基本手当の受給資格者となり得る。

### 問6 老齢年金の繰上げ・繰下げ
公的年金の繰上げ・繰下げに関する次の記述のうち、**最も適切**なものはどれか。

1. 老齢基礎年金を繰り上げた場合の減額率は、繰り上げた月数×0.7%である。
2. 老齢基礎年金の繰下げは最長70歳までであり、増額率は最大42%である。
3. 老齢基礎年金と老齢厚生年金の繰上げは、同時に行わなければならない。

### 問7 遺族年金

1. 遺族基礎年金を受給できる遺族は、死亡した者に生計を維持されていた「子のある配偶者」または「子」である。
2. 遺族厚生年金の額は、原則として、死亡した者の老齢厚生年金の報酬比例部分の3分の2に相当する額である。

4. 中高齢寡婦加算は、夫の死亡当時40歳以上65歳未満で子のない妻などが受ける遺族厚生年金に加算される。

### 問8 確定拠出年金

1. 個人型年金(iDeCo)の掛金は、その全額が小規模企業共済等掛金控除として所得控除の対象となる。
2. 国民年金第1号被保険者のiDeCoの拠出限度額は、国民年金基金の掛金・付加保険料と合わせて月額68,000円である。
3. 老齢給付金を年金で受け取った場合、雑所得として公的年金等控除の対象となる。
4. 老齢給付金を一時金で受け取った場合、一時所得として課税される。

### 問9 教育資金
教育資金に関する次の記述のうち、**最も不適切**なものはどれか。

1. 国の教育一般貸付(教育ローン)の融資限度額は、海外留学など一定の場合を除き、学生1人につき350万円である。
2. 国の教育一般貸付の資金使途は入学金・授業料に限られ、受験費用や在学のためのアパートの家賃は対象とならない。

### 問10 住宅ローン
住宅ローンに関する次の記述のうち、**最も不適切**なものはどれか。

1. フラット35の融資金利は全期間固定金利であり、その利率は取扱金融機関がそれぞれ独自に定めている。
2. フラット35の融資金利は、借入申込時点ではなく融資実行時点の金利が適用される。
3. 住宅ローンの一部繰上げ返済では、返済期間・金額など他の条件が同一であれば、返済額軽減型の方が期間短縮型よりも利息の軽減効果が大きい。
4. フラット35では、保証人は不要であり、繰上げ返済の手数料もかからない。

## 解答・解説

**問1 正解 1** — 税務書類(確定申告書)の作成は有償・無償を問わず税理士の独占業務。2・3・4はいずれも資格がなくても可能な行為。

**問2 正解 2** — 「今ある元本を運用しながら毎年取り崩す→毎年の受取額」は**資本回収係数**。逆に「毎年○円受け取るには今いくら必要か」は年金現価係数。この対の使い分けが最頻出。

**問3 正解 4** — 支給期間は2022年改正により「支給開始日から**通算**1年6ヶ月」。途中で復職した期間はカウントされない。「連続して」が誤り。1〜3は適切。

**問4 正解 4** — 1: 第2号は特定疾病による場合のみ。2: 認定は市町村。3: 第1号は所得により2割・3割負担がある。

**問5 正解 2** — 自己都合・定年退職の所定給付日数は最長**150日**(20年以上)。330日は倒産・解雇等(特定受給資格者)の最長日数。

**問6 正解 3** — 繰上げは基礎・厚生**同時**が必須。繰下げは別々に可能(選択肢4が誤りの理由)。繰上げ減額率は0.4%/月、繰下げは75歳まで最大+84%。

**問7 正解 2** — 遺族厚生年金は報酬比例部分の**4分の3**。

**問8 正解 4** — 一時金受取りは**退職所得**(退職所得控除の対象)。一時所得ではない。

**問9 正解 2** — 教育一般貸付は受験費用、下宿の家賃・敷金、教材費、通学費用なども対象になる。

**問10 正解 3** — 利息軽減効果が大きいのは**期間短縮型**。1・2・4はフラット35の定番の正しい記述。
