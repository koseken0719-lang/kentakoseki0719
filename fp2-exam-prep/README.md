# FP2級 直前対策問題集(2026年8月21日受験用)

AM学科・PM実技の同日受験に向けた、**過去10年分(2016年5月〜2026年5月CBT)の出題傾向に基づく頻出論点特化型**の対策教材です。

## 試験概要(CBT方式)

| 項目 | 学科(AM) | 実技(PM) |
|---|---|---|
| 時間 | 120分 | 90分 |
| 形式 | 四肢択一 60問 | 記述式(電卓画面内蔵) |
| 合格基準 | 60点満点中 **36点以上(6割)** | 6割以上 |
| 法令基準日 | 2026年4月1日(2026年6月〜2027年5月実施分) | 同左 |

- 学科は6分野から**各10問ずつ均等に**出題されます。苦手分野を作らないことが最重要です。
- 実技は日本FP協会「資産設計提案業務」を想定した計算問題を中心に、金財「個人資産相談業務」とも共通する頻出計算をカバーしています。

## 8月21日までの学習プラン(残り約5週間)

- **〜7月末(基礎固め)**: 本教材の6分野を1日1分野×2周。間違えた問題に印を付ける。
- **8月1日〜14日(過去問演習)**: 過去問サイト(過去問ドットコム・FP2級ドットコム等)で年度別に最低6回分を通しで解く。学科は1回分を90分以内で解く練習。
- **8月15日〜19日(弱点潰し)**: 印を付けた問題と実技計算パターン(07)を毎日全問解き直す。実技は電卓なし(CBTは画面内電卓)を想定して練習。
- **8月20日(前日)**: 数字の最終確認(下記「直前暗記カード」)。夜更かし禁止。
- **8月21日当日**: AM学科→昼休みに07の計算パターンだけ見直し→PM実技。

## 直前暗記カード(試験前日に見る数字)

- 6つの係数の使い分け(01参照)
- 傷病手当金: 通算**1年6ヶ月**・標準報酬日額の**2/3**
- 老齢年金 繰上げ **▲0.4%/月**・繰下げ **+0.7%/月**(75歳まで、最大+84%)
- 生命保険料控除(2012年以降契約): 3区分 各**4万円**・計**12万円**(所得税)
- 死亡保険金の非課税: **500万円×法定相続人の数**
- 地震保険: 主契約の**30〜50%**、建物**5,000万**・家財**1,000万**上限
- 自賠責: 死亡**3,000万**・後遺障害最高**4,000万**・傷害**120万**
- 預金保険: 元本**1,000万円**+利息(決済用預金は全額)
- 新NISA: つみたて**120万**/成長**240万**/生涯**1,800万**(うち成長1,200万)
- 退職所得控除: **40万×20年+70万×超過年数**(端数切上げ)、×1/2
- 医療費控除: **10万円**(総所得200万未満は5%)超、上限200万
- 住宅ローン控除: 年末残高×**0.7%**
- 容積率の前面道路制限: 住居系**4/10**・その他**6/10**
- 開発許可: 市街化区域**1,000㎡以上**
- 固定資産税 住宅用地: 200㎡以下**1/6**
- 居住用3,000万特別控除+10年超軽減税率(6,000万以下部分**14.21%**)
- 相続税基礎控除: **3,000万+600万×法定相続人**
- 配偶者の税額軽減: **1億6,000万円**or法定相続分
- 小規模宅地: 居住**330㎡・80%**/事業**400㎡・80%**/貸付**200㎡・50%**
