# 第6分野 相続・事業承継(学科 問51〜60)

## 頻出論点まとめ(過去10年の出題傾向)

### ★★★ ほぼ毎回出題
1. **贈与と贈与税**
   - 贈与契約は**諾成契約**(書面不要で成立)。**書面によらない贈与は、履行前であれば各当事者が解除できる**(履行後は不可)。死因贈与は**相続税**の課税対象。
   - 暦年課税: 基礎控除**110万円**は**受贈者ごと**に年間110万円(複数人からもらっても合計110万円)。
   - **相続時精算課税**: **60歳以上の父母・祖父母→18歳以上の子・孫**。特別控除**2,500万円**+**2024年から年110万円の基礎控除**(この110万円分は相続財産に加算されない)。超過分は一律**20%**。いったん選択すると**暦年課税に戻れない**。
   - **贈与税の配偶者控除**: **婚姻期間20年以上**、居住用不動産またはその取得資金、**2,000万円**(基礎控除と合わせ2,110万円)。同一配偶者からは一生に1回。
   - 直系尊属からの**教育資金一括贈与1,500万円**(学校等以外500万円)/**結婚・子育て資金1,000万円**/**住宅取得等資金**(省エネ等住宅1,000万円・その他500万円)。
   - 生前贈与加算: 相続開始前**7年以内**(2024年から3年→7年へ順次延長)の暦年贈与は相続財産に加算(延長4年分は総額100万円まで加算不要)。
   - 贈与税の申告: 翌年**2月1日〜3月15日**。
2. **相続人と法定相続分**(毎回計算あり)
   - 順位: 第1順位**子**(配偶者1/2・子1/2)→第2順位**直系尊属**(配偶者2/3・尊属1/3)→第3順位**兄弟姉妹**(配偶者3/4・兄弟1/4)。
   - **代襲相続**: 子の代襲は孫・曾孫と続くが、**兄弟姉妹の代襲は甥・姪まで(一代限り)**。**相続放棄した者の子は代襲しない**(欠格・廃除は代襲する)。
   - 実子と養子、嫡出子と非嫡出子の相続分は**同等**。父母の一方のみ同じ兄弟姉妹(半血)は全血の**1/2**。胎児は生まれたものとみなす。
3. **相続の承認・放棄**
   - 相続開始を知った時から**3ヶ月以内**に、家庭裁判所へ。**放棄は単独で可**、**限定承認は共同相続人全員で**。
   - 放棄すると**初めから相続人でなかったものとみなされる**が、死亡保険金は受け取れる(**非課税枠は使えない**)。
4. **遺言・遺留分**
   - **自筆証書遺言**: 全文・日付・氏名を自書し押印(**財産目録はパソコン作成可**、毎葉に署名押印)。家庭裁判所の**検認が必要**(**法務局保管制度を利用すれば検認不要**)。証人不要。
   - **公正証書遺言**: **証人2人以上**の立会い(**推定相続人・受遺者やその配偶者・直系血族は証人になれない**)。原本は公証役場保管、**検認不要**。
   - 遺言は**15歳以上**で可能。いつでも**撤回自由**、抵触する部分は後の遺言が優先。
   - **遺留分**: 総体的遺留分は**相続財産の1/2**(**直系尊属のみが相続人の場合は1/3**)。**兄弟姉妹に遺留分はない**。遺留分侵害額請求権は**金銭**の請求。時効: 侵害を知った時から**1年**・相続開始から10年。
5. **相続税の計算**(超頻出)
   - **基礎控除=3,000万円+600万円×法定相続人の数**。法定相続人の数には**放棄した者も含める**。**養子は実子がいれば1人、いなければ2人まで**カウント。
   - **死亡保険金・死亡退職金の非課税: 各500万円×法定相続人の数**(相続人が受け取った場合のみ)。
   - 弔慰金の非課税: 業務上の死亡**36ヶ月分**・業務外**6ヶ月分**(普通給与)。
   - 債務控除: 借入金・未払税金は控除**可**、**香典返し・初七日・法要費用・遺言執行費用は控除不可**(通夜・葬式費用は可)。
   - **配偶者の税額軽減**: **1億6,000万円**または配偶者の法定相続分相当額のいずれか**多い**金額まで非課税。**申告が要件**(軽減の結果ゼロでも申告必要)。婚姻期間の要件なし。
   - **2割加算**: 配偶者・1親等の血族(子・父母)**以外**(兄弟姉妹、甥姪、孫養子など)。**代襲相続人である孫は加算されない**が、**代襲相続人でない孫養子は加算される**。
   - 申告・納付: 相続開始を知った日の翌日から**10ヶ月以内**。延納(担保等の要件)・**物納**(延納でも困難な場合、順位あり)。**準確定申告は4ヶ月以内**。
6. **財産評価(宅地)**(超頻出)
   - 路線価方式: **路線価×奥行価格補正率×地積**。倍率方式: 固定資産税評価額×倍率。
   - **自用地/借地権=自用地×借地権割合/貸宅地(底地)=自用地×(1−借地権割合)/貸家建付地=自用地×(1−借地権割合×借家権割合×賃貸割合)**。
   - 貸家=固定資産税評価額×(1−借家権割合×賃貸割合)。使用貸借(タダ貸し)の土地は**自用地評価**。
7. **小規模宅地等の特例**(超頻出)

   | 区分 | 限度面積 | 減額 |
   |---|---|---|
   | 特定居住用宅地等 | **330㎡** | **80%** |
   | 特定事業用宅地等 | **400㎡** | **80%** |
   | 貸付事業用宅地等 | **200㎡** | **50%** |
   - 配偶者が取得→**無条件で適用**。同居親族→申告期限まで所有・居住継続。特定居住用+特定事業用は**完全併用で最大730㎡**。適用には**申告が必要**。
8. **その他の財産評価・事業承継**
   - 上場株式: **課税時期の終値/当月・前月・前々月の毎日の終値平均**の**4つのうち最も低い額**。
   - 取引相場のない株式: 同族株主等→**類似業種比準方式・純資産価額方式・併用方式**、同族株主以外→**配当還元方式**。
   - 生命保険契約に関する権利: **解約返戻金相当額**で評価。ゴルフ会員権: 取引価格×70%。
   - 非上場株式等についての贈与税・相続税の納税猶予(事業承継税制)。
   - 成年後見制度: 法定後見(**後見・保佐・補助**の3類型)、任意後見契約は**公正証書**で締結。

## 対策問題(10問)

### 問1 贈与契約・贈与税
贈与に関する次の記述のうち、**最も不適切**なものはどれか。

1. 贈与契約は、当事者の合意のみで成立し、書面の作成を要しない。
2. 書面によらない贈与は、既に履行が終わった部分についても、各当事者が解除することができる。
3. 死因贈与により取得した財産は、贈与税ではなく相続税の課税対象となる。
4. 暦年課税の基礎控除額110万円は、受贈者1人につき年間110万円である。

### 問2 相続時精算課税
相続時精算課税制度に関する次の記述のうち、**最も不適切**なものはどれか。

1. 原則として、贈与年の1月1日において60歳以上の父母・祖父母から18歳以上の子・孫への贈与が対象となる。
2. 特別控除額2,500万円を超える部分には、一律20%の贈与税が課される。
3. 2024年1月1日以後の贈与については、特別控除とは別に年110万円の基礎控除が認められる。
4. 相続時精算課税を選択した受贈者は、その後、同じ贈与者からの贈与について暦年課税に変更することができる。

### 問3 法定相続分(計算)
被相続人Aの相続人は、妻B、長男C、および先に死亡した二男Dの子(Aの孫)E・Fの計4人である。この場合の孫Eの法定相続分として、**最も適切**なものはどれか。

1. 8分の1
2. 4分の1
3. 6分の1
4. 12分の1

### 問4 相続の承認・放棄
相続の承認・放棄に関する次の記述のうち、**最も適切**なものはどれか。

1. 相続の放棄は、自己のために相続の開始があったことを知った時から3ヶ月以内に、家庭裁判所に申述しなければならない。
2. 相続の放棄は、共同相続人全員が共同して行わなければならない。
3. 限定承認は、相続人が単独で行うことができる。
4. 相続を放棄した者の子は、その者を代襲して相続人となる。

### 問5 遺言
遺言に関する次の記述のうち、**最も不適切**なものはどれか。

1. 自筆証書遺言に添付する財産目録は、パソコンで作成したものでもよい(毎葉への署名押印が必要)。
2. 法務局(遺言書保管所)に保管された自筆証書遺言は、家庭裁判所の検認が不要である。
3. 公正証書遺言の作成には証人2人以上の立会いが必要であり、遺言者の推定相続人も証人となることができる。
4. 遺言者は、いつでも、遺言の方式に従って、遺言の全部または一部を撤回することができる。

### 問6 遺留分
遺留分に関する次の記述のうち、**最も適切**なものはどれか。

1. 被相続人の兄弟姉妹にも、遺留分が認められる。
2. 相続人が直系尊属のみである場合の総体的遺留分は、遺留分算定の基礎となる財産の3分の1である。
3. 遺留分侵害額請求権は、遺贈の目的物そのものの返還を請求する権利である。
4. 遺留分侵害額請求権は、相続の開始および遺留分を侵害する贈与・遺贈があったことを知った時から3年で時効消滅する。

### 問7 相続税の基礎控除・非課税(計算)
被相続人の相続人は、妻、長女、二女の3人であり、二女は相続を放棄した。相続税の課税価格の合計額から控除される遺産に係る基礎控除額として、**最も適切**なものはどれか。

1. 3,600万円
2. 4,200万円
3. 4,800万円
4. 5,400万円

### 問8 相続税の税額計算
相続税に関する次の記述のうち、**最も不適切**なものはどれか。

1. 「配偶者に対する相続税額の軽減」により、配偶者が取得した財産が1億6,000万円または配偶者の法定相続分相当額のいずれか多い金額までであれば、配偶者に相続税はかからない。
2. 「配偶者に対する相続税額の軽減」の適用を受けるためには、相続税の申告書を提出する必要がある。
3. 被相続人の兄が相続により財産を取得した場合、その者の相続税額に2割加算が行われる。
4. 代襲相続人である孫が相続により財産を取得した場合、その者の相続税額に2割加算が行われる。

### 問9 宅地の評価
相続税における宅地の評価に関する次の記述のうち、**最も不適切**なものはどれか。

1. 路線価方式による自用地の評価額は「路線価×奥行価格補正率×地積」により計算される。
2. 貸家建付地の評価額は「自用地評価額×(1−借地権割合×借家権割合×賃貸割合)」により計算される。
3. 借地権の評価額は「自用地評価額×(1−借地権割合)」により計算される。
4. 子が親の土地を使用貸借で借りて自宅を建てている場合、相続時のその土地は自用地として評価される。

### 問10 小規模宅地等の特例
小規模宅地等についての相続税の課税価格の計算の特例に関する次の記述のうち、**最も適切**なものはどれか。

1. 特定居住用宅地等に該当する場合、限度面積240㎡まで評価額の80%を減額できる。
2. 配偶者が被相続人の居住用宅地を取得した場合、申告期限までの居住継続・保有継続の要件を満たさなければ適用を受けられない。
3. 貸付事業用宅地等に該当する場合、限度面積200㎡まで評価額の50%を減額できる。
4. この特例の適用を受けて相続税額がゼロになる場合、相続税の申告書の提出は不要である。

## 解答・解説

**問1 正解 2** — 書面によらない贈与でも、**履行が終わった部分は解除できない**(解除できるのは履行前のみ)。

**問2 正解 4** — 相続時精算課税はいったん選択すると**撤回不可**、暦年課税には戻れない。

**問3 正解 1** — 妻B=1/2。子の相続分1/2を長男Cと(死亡した)二男Dで分け、C=1/4、D分1/4をE・Fが代襲して各**1/8**。代襲相続人は被代襲者の相続分を頭割り——この型は毎回出る。

**問4 正解 1** — 2: 放棄は**単独**で可。3: 限定承認は**全員共同**。4: 放棄者の子は代襲**しない**。

**問5 正解 3** — 推定相続人・受遺者およびその配偶者・直系血族は**証人になれない**。

**問6 正解 2** — 直系尊属のみの場合は**1/3**(それ以外は1/2)。1: 兄弟姉妹に遺留分なし。3: 請求できるのは**金銭**。4: 時効は知った時から**1年**。

**問7 正解 3** — 基礎控除の計算では**放棄はなかったものとして**法定相続人3人でカウント: 3,000万+600万×3=**4,800万円**。

**問8 正解 4** — **代襲相続人である孫は2割加算の対象外**(1親等の血族と同様に扱う)。代襲相続人でない孫養子は加算対象——この対比が定番の引っかけ。

**問9 正解 3** — 借地権=自用地×**借地権割合**。「×(1−借地権割合)」は**貸宅地(底地)**の式。

**問10 正解 3** — 1: 特定居住用は**330㎡**。2: 配偶者は**無条件**で適用可。4: 税額ゼロでも**申告必要**。
