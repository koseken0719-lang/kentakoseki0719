# NBF 電気料金無料診断 申込フォーム

商工会議所青年部 全国大会「NBF」（2026年10月14日・水戸）で上映する動画から誘導する、
電気料金の無料診断の申込フォーム一式。

| ファイル | 内容 |
|---|---|
| `create_form.gs` | Apps Script に貼り付けて実行すると、仕様どおりのフォームと回答用スプレッドシートを自動生成する |
| `form_manuscript.md` | 手動で転記する場合の完成原稿（設定・チェックリスト・未確認事項つき） |

## 状態

**未公開・回答受付停止。** 個人情報に関する問い合わせ窓口とプライバシーポリシーURLが
未確認のため、`【要確認】` を差し替えるまで回答受付を開始しない設計にしている。

## 補足

- Google Forms の API 連携が本環境にないため、フォーム自体はこのリポジトリからは作成していない。
- テーマ色（ネイビー `#1B2A4A`）は Apps Script から設定できないため、作成後に手動設定する。
- ロゴは提供されていないため作成していない。
