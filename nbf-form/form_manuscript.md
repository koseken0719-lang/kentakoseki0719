# 電気料金の無料診断・利益改善のご相談 ／ Googleフォーム完成原稿

NBF（商工会議所青年部 全国大会・2026年10月14日 水戸）上映動画からの誘導フォーム。
手動で転記する場合は、この原稿を上から順にそのままコピー＆ペーストしてください。

---

## 1. フォームのタイトル

```
電気料金の無料診断・利益改善のご相談
```

## 2. フォームの説明（冒頭の説明文）

```
毎月の電気料金に、見直しの余地があるか確認してみませんか。

まずは下記よりお申し込みください。担当者から、電気明細の提出方法をご案内します。

電気料金の診断は無料です。切替等のサービスをご利用いただく場合の条件は、別途ご説明します。

ご希望の方には、株式会社スフェノスによる販管費全体の見直し相談もご案内します。こちらの相談内容・費用は事前にご案内します。

このフォームでは、電気明細や決算書の添付は不要です。
```

---

## 3. 質問項目（この順番で設定）

### Q1
- 質問文：`会社名・屋号`
- 形式：記述式（短文）
- 必須：**する**

### Q2
- 質問文：`お名前`
- 形式：記述式（短文）
- 必須：**する**

### Q3
- 質問文：`所属する商工会議所・青年部など`
- 形式：記述式（短文）
- 必須：しない

### Q4
- 質問文：`メールアドレス`
- 形式：記述式（短文）
- 必須：**する**
- 回答の検証：**オン** → 「テキスト」→「メールアドレス」
  - エラーテキスト：`メールアドレスの形式でご入力ください。`
- ※ フォーム設定の「メールアドレスを収集する」は**オフ**のまま（Googleログインを求めず、本人が入力する方式）

### Q5
- 質問文：`電話番号`
- 形式：記述式（短文）
- 必須：しない
- 説明：`お電話での連絡をご希望の場合はご記入ください。`
- 回答の検証：**設定しない**（ハイフンの有無などで制限しない）

### Q6
- 質問文：`ご希望の内容`
- 形式：ラジオボタン（単一選択）
- 必須：**する**
- 説明：`販管費全体の見直し相談は、株式会社スフェノスが担当します。相談内容・費用は事前にご案内します。`
- 選択肢（事前選択なし・「その他」なし）：
  1. `電気料金の無料診断を希望する`
  2. `電気料金の無料診断と、販管費全体の見直し相談を希望する`
  3. `まずはサービスの説明を聞きたい`

### Q7
- 質問文：`ご質問・連絡事項`
- 形式：段落（記述式・長文）
- 必須：しない
- 説明：`ご質問や、ご希望の連絡時間帯などがあればご記入ください。決算情報などの詳細は、ここには記載不要です。`

### 見出し（タイトルと説明を追加／ページは分けない）
- タイトル：`個人情報の取り扱い`
- 説明：下記「4. 個人情報の取り扱い」の本文をそのまま貼り付け

### Q8
- 質問文：`個人情報の取り扱いへの同意`
- 形式：チェックボックス
- 必須：**する**
- 選択肢（事前チェックなし・「その他」なし）：
  1. `下記の個人情報の取り扱いに同意する`

## 4. 個人情報の取り扱い（Q8の直前の見出しに貼る本文）

> **【要確認】の2か所を実際の情報に差し替えるまで、回答受付は開始しないでください。**

```
■ 受付・管理主体
本フォームの回答は、株式会社TREX（東京都渋谷区渋谷2-3-4 スタービル青山3階／代表取締役 森山佳樹）が受け付け、管理します。

■ 利用目的
(1) 本申込みへの対応およびご連絡
(2) 電気料金の無料診断に必要な資料（電気明細）の提出方法のご案内
(3) ご希望いただいたサービスに関するご連絡・ご提案
上記以外の目的には利用しません。メールマガジンの配信や、ご希望のないサービスのご案内には利用しません。

■ 第三者への提供
上記「ご希望の内容」で②「電気料金の無料診断と、販管費全体の見直し相談を希望する」を選択された方についてのみ、販管費全体の見直し相談を担当する株式会社スフェノスへ、本フォームにご入力いただいた内容（会社名・屋号、お名前、所属する商工会議所・青年部など、メールアドレス、電話番号、ご希望の内容、ご質問・連絡事項）を提供します。提供の目的は、販管費全体の見直し相談に関するご連絡・ご提案です。
①または③を選択された方の情報は、株式会社スフェノスへ提供しません。
※ 株式会社TREXと株式会社スフェノスは別の法人です。電気料金の診断は株式会社TREX、販管費全体の見直し・財務コンサルティングは株式会社スフェノスが担当します。

■ 個人情報に関するお問い合わせ窓口
【要確認：個人情報に関するお問い合わせ窓口（担当部署／メールアドレス／電話番号）】

■ プライバシーポリシー
株式会社TREX：【要確認：株式会社TREX プライバシーポリシーURL】
株式会社スフェノス：【要確認：株式会社スフェノス プライバシーポリシーURL】
```

## 5. 送信完了メッセージ

設定 → プレゼンテーション → 「確認メッセージ」を編集

```
お申し込みありがとうございます。

ご入力いただいた連絡先へ、担当者からご連絡します。

電気料金の無料診断をご希望の方には、電気明細の提出方法をご案内します。

販管費全体の見直し相談をご希望の方には、相談の進め方と費用を事前にご案内します。

森瀬会長へ直接ご相談いただくこともできます。
```

## 6. フォームの設定

### 「回答」タブ
| 項目 | 設定 |
|---|---|
| メールアドレスを収集する | **オフ**（Googleログイン不要・Q4で本人が入力） |
| 回答のコピーを回答者に送信 | しない |
| 回答を1回に制限する | **オフ** |
| 回答の編集を許可する | オフ |
| 概要グラフとテキストの回答を表示する | **オフ**（他の回答者に見えないように） |
| ＜組織名＞のユーザーに限定する | **オフ**（表示される場合） |
| 回答の受付 | **停止**（未確認事項の差し替えが済むまで） |

### 「プレゼンテーション」タブ
| 項目 | 設定 |
|---|---|
| 進行状況バーを表示 | オフ（1ページ構成） |
| 質問の順序をシャッフルする | **オフ** |
| 別の回答を送信するためのリンクを表示 | オフ |
| 確認メッセージ | 上記「5.」の文章 |

### 「デフォルト」タブ / その他
- クイズにする：**オフ**
- ファイルのアップロード（添付）：**設定しない**
- 自動返信メール等の営業目的の配信：**設定しない**

### 回答先
- 「回答」タブ →「スプレッドシートにリンク」→「**新しいスプレッドシートを作成**」
- 名前：`NBF_電気料金無料診断_申込管理`
- 作成後、そのスプレッドシートは**共有しない**（作成者のみ）

## 7. デザイン

右上のパレットアイコンから設定（Apps Scriptでは設定できないため手動）

| 項目 | 設定値 |
|---|---|
| テーマの色 | カスタム → `1B2A4A`（ネイビー） |
| 背景色 | 白（最も明るいもの） |
| フォントスタイル | 基本 |
