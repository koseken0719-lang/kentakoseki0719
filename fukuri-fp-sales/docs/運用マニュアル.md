# 運用マニュアル

## 0. 実運用開始までに人が行うこと（チェックリスト）

- [ ] **所属代理店（ファイナンシャルアライアンス株式会社）の承認**を得る（営業文面・案内PDF・社内告知文・予約ページ・規約ひな形）。取得後、`config/settings.yaml` の `compliance.agency_approved: true` と承認日・管理番号を記入
- [ ] `config/settings.yaml` の `sender`（氏名・住所・電話・メール・URL・予約ページのベースURL）を記入
- [ ] 駅別所要時間表（`stations`）を確認・修正（概算値のため）
- [ ] 追加調査リストの企業の移動時間を乗換案内で確認し、01_企業マスターの「移動時間(分)」「移動時間区分」に入力
- [ ] 仮キー（`仮-`）の企業の法人番号を国税庁法人番号公表サイトで確認
- [ ] gBizINFO APIの利用申請（https://info.gbiz.go.jp/）→ `GBIZINFO_API_TOKEN`
- [ ] （推奨）Googleサービスアカウントを作成しスプレッドシートを共有 → `GOOGLE_APPLICATION_CREDENTIALS`、`SFS_SPREADSHEET_ID`
- [ ] 個人情報保護方針・利用規約のひな形を専門家が確認
- [ ] 予約システム（Googleカレンダー予約スケジュール等）を用意
- [ ] 07_士業・紹介パートナー に既存人脈を登録（紹介可能企業の法人番号を記入すると最優先になる）
- [ ] 定期実行（`scheduled/README.md`）を登録

環境変数は Claude Code のクラウド環境設定（環境変数・シークレット）に登録する。リポジトリやチャットに貼らない。

## 1. 毎日（平日・約15〜30分）
1. 定期実行が作る「本日の営業タスク」を確認する。
2. Gmailの下書きと営業キット（`output/outreach/`）を読み、**最新の公開情報と相違がないか確認**して、問題なければ自分で送信／投函／架電する。
3. 実施した接触を 03_営業活動履歴 に記録する（チャネル・結果・承認者）。
   CLI：`python -m sfs activity <法人番号> メール 未返信 --approver 氏名`
4. 「不要」「送らないで」と言われたら、結果を **受信拒否** で記録する（自動で 10_営業停止リスト に入り、以後除外）。
5. アポが取れたら 04_法人商談管理 に登録する。

## 2. 毎週
- **月曜**：新規企業調査（定期実行）。報告の「拒否数」「未確認が多い項目」を確認する。
- **金曜**：週次改善レポート（09シート）を読み、翌週の重点を決める。

## 3. 毎月末
- 月次レポート（`output/reports/`）で、発掘数・アプローチ数・返信率・商談化率・導入率・対象従業員数・相談予約/実施件数・利用率・面談1件あたり獲得原価、業種別/地域別/チャネル別の成果を確認する。
- 改善案を採否判断し、必要なら `config/settings.yaml` の目標値・配点・ケイデンスを見直す。
- 導入企業へ月間利用実績レポート（集計のみ）を送る。

## 4. 導入が決まったら
```bash
python -m sfs onboard-register <法人番号> --employees 80 --dept 総務部
python -m sfs onboard-build <法人番号>          # output/onboarding/<企業コード>/ に一式
python -m sfs consult-record 2026-12 <法人番号> 6 5 --themes '{"住宅":2,"保険":3}'
python -m sfs usage-report 2026-12 <法人番号>
```
予約ページ（index.html）と規約は、承認後に `sender.booking_base_url/<企業コード>/` へ配置する。相談予約のカレンダー予定には `[FP相談:<企業コード>]` をタイトルに入れる。

## 5. スプレッドシートとの同期
- 直結（推奨）：`python -m sfs sync pull` → 処理 → `python -m sfs sync push`
- コネクタ：Claudeがシートを読み書きする。`python -m sfs values export <シート> --out x.json` / `values import <シート> --file x.json`
- 初期作成：`python -m sfs export-xlsx` のファイルをGoogleドライブにアップロード（スプレッドシートに変換）

## 6. トラブル対応
| 症状 | 対処 |
|---|---|
| `取り込み拒否` | 理由（出典なし・法人番号不一致など）を確認。出典を補えない数字は入れない |
| 優先営業リストに出てこない | 01の「対象区分」「追加調査理由」を確認。従業員数・移動時間を補完して `score` |
| `BudgetExceeded` | 当月の上限到達。`budget` を見直すか翌月まで待つ |
| Gmail下書きが作られない | 代理店承認フラグ、差出人情報、公開メールの有無、営業ステータス（未着手のみ）を確認 |
| 誤って営業停止にした | 10シートから該当行を人が削除し、01のステータスを戻して `score`（理由を備考に残す） |
