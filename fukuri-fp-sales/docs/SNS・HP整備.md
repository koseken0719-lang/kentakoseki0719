## 4. 投稿の型（週2本・人事／総務／経営者向け）

読み手は従業員ではなく、導入を決める人事・総務・経営者です。売り込みは4本に1本までにします。

| 型 | 例（書き出し） |
|---|---|
| 総務の「あるある」 | 「退職金っていくらもらえるんですか」と聞かれて、規程を開いて答えた経験はありませんか。制度の説明はできても、「自分の場合どうすればいいか」には答えにくいものです。 |
| 制度の豆知識 | 企業型DCを導入している会社には、加入者への継続的な投資教育が努力義務とされています。導入時に一度説明したきり、になっていませんか。 |
| 手取りと総報酬 | 新入社員は、初任給の「手取り」で会社を比べます。社会保険料の会社負担、退職金、手当を合わせた金額を、入社時に一度見せるだけで受け止め方が変わります。 |
| 季節の話題 | 年末調整の時期です。総務に集中する質問のうち、控除の基本は30分の社内セミナーでまとめて解消できます。（1〜2月：確定申告・NISA／4月：新入社員／6〜7月：安全大会／10〜11月：年末調整・DC） |
| 研修の中身 | 新入社員研修で必ず聞く質問があります。「給与明細の『控除』の欄、何に使われているか説明できますか」。 |
| 考え方 | 福利厚生は「割引」より「相談できる相手」のほうが、使われたときの効き目が大きいと考えています。その理由を書きます。 |
| 活動報告 | （実施後に）先日、◯◯業の会社で定年前セミナーを実施しました。事前に多かった質問は……。※会社名・個人が特定される内容は書かない。許可を得た範囲で |
| サービス案内 | 従業員50名の会社なら、1人あたり月1,000円。社外に「お金の相談窓口」を持つという選択肢について。 |

最初の2週間で「総務のあるある」「制度の豆知識」「手取りと総報酬」「サービス案内」の4本を投稿し、プロフィールを訪れた人に内容が伝わる状態にしてから、フォーム営業を始めます。

## 5. フォーム営業と連動させる順番

1. LPを公開（代理店承認後）→ `config/settings.yaml` の `sender.lp_url` に入れる（フォーム文面にURLが入る）
2. 会社サイトの事業内容にサービスを追加し、LPへリンク
3. SNSのプロフィールと固定投稿を更新、投稿を4本
4. フォーム営業を開始（1日10社）。返信が来た会社の業種・切り口を見て、投稿の題材にする
