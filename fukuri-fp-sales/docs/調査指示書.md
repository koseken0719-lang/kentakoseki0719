# 企業リサーチ指示書（公開情報のみ・捏造厳禁）

目的: 東京都内の実在中小企業について、法人営業の事前調査として**公開情報のみ**を収集し、JSONファイルに保存する。

## 絶対ルール
- 捏造禁止。自分でページを開いて確認できた事実のみ記入する。確認できない項目は文字列 "未確認" (数値項目は null) にする。推測で埋めない。
- 記憶や一般知識で埋めない。必ず今回のWeb検索/ページ取得で確認し、その情報源URLを記録する。
- 公開ページのみ。ログイン、フォーム送信、問い合わせ送信、アクセス制限回避、大量連続アクセスは禁止。乗換案内サイト・地図サイトの自動取得はしない。
- 個人情報は「公式サイト等で公開されている代表者名・役職」以外収集しない（担当者個人名・個人メール・個人SNSは不要）。
- 実在が確認できない企業、公式サイトが見つからない企業は含めない。
- 大企業の子会社・支店ではなく、原則その地域に本社がある独立系中小企業を優先（子会社の場合は notes に明記）。

## 対象条件
- 従業員数 50〜100名が理想。確認値が30〜300名なら含めてよい（スコアで調整する）。従業員数が確認できない企業は最大1社まで（"未確認"のまま）。
- 従業員数の情報源は 公式サイト会社概要 > 公式採用ページ > gBizINFO/しょくばらぼ > 求人媒体 の優先順。情報源URLと「いつ時点の数字か」を記録。
- 採用活動をしている／福利厚生・健康経営・働きやすさを打ち出している企業を優先して探す。

## 出力
- 指定されたパスに UTF-8 の JSON 配列（上記オブジェクトの配列）として保存する。JSONとして正しいことを `python3 -c "import json;json.load(open(PATH))"` で検証する。
- 指定社数に届かなくてもよい。質を優先し、確認できた企業だけを入れる。
- 最終報告は「保存パス、社数、各社の名前と従業員数、未確認が多かった項目、気付いた注意点」を簡潔に。
