# 中小企業向け サイバーセキュリティ対策 × サイバー保険 共同セミナー企画書

作成日: 2026年7月12日（ドラフト v1）

---

## 1. 企画の背景と狙い

- はてなベース株式会社（会計×開発で中小企業のバックオフィスDXを支援。freee・kintone中心）は、当代理店にてIT業務過誤賠償責任保険にご加入済み。
- はてなベースの顧客・見込み顧客は「クラウド会計・業務システムを導入した/しようとしている中小企業」であり、**ITの利活用が進んでいる分、サイバーリスクへの露出が大きく、かつITリテラシーが高いため話が通じやすい**層。
- 参考事例として、サイバー保険特化型代理店 RiMiX株式会社・今徳良氏のセミナー資料（2026年3月）を分析。「中小企業こそ狙われる」という脅威の実態から入り、対策の限界→保険の必要性へ導く構成、専門用語を使わないトークが有効であることを確認。
- 本企画は同じ骨格を「代理店向け」から「**中小企業の経営者・総務向け**」に置き換え、はてなベースの「実務対策」と当代理店の「リスクファイナンス（保険）」を組み合わせた共同セミナーとする。

## 3. 双方（三方）のメリット設計

### はてなベース側のメリット
1. **顧客接点の強化**: 既存顧客への付加価値提供（保守契約・顧問契約の継続率向上）。
2. **見込み客の育成**: セミナーを入口に、バックオフィスDX・システム改善・セキュリティ設定支援の案件化。
3. **信頼性の訴求**: 「自社もIT業務過誤賠償責任保険に加入し、万一に備えているITパートナー」という差別化。発注側の中小企業にとって"保険に入っているベンダー"は安心材料であり、これ自体が営業トークになる。

### 当代理店側のメリット
1. **新規開拓チャネル**: はてなベースの顧客基盤（ITリテラシーの高い中小企業＝サイバー保険の最適見込み客）へのアクセス。今徳氏の実績でも「開拓リストの質＝ITリテラシーの高い企業」が成功の鍵、決裁者アポ取得率30%超。
2. **多種目販売の起点**: サイバー保険のヒアリングから既契約確認→賠償・労災・生保などへ展開（今徳氏メソッドと同様）。
3. **競合が少ない切り口**: サイバー保険を提案できる代理店はまだ少なく、先行者利益が大きい。

### 参加企業（中小企業）のメリット
- 「実態（脅威）→無料でできる対策→お金の備え（保険）」を1回で学べる。
- 押し売りではなく「チェックリスト・診断・見積り」という持ち帰れる実益がある。

## 4. プログラム構成案（90分）

RiMiXセミナーの流れ（脅威の実態→対策の限界→保険は最後の砦）を経営者向けに再構成。

### オープニング（5分）｜両社
- 共催の経緯紹介。「なぜIT会社が保険の話を？」→ **はてなベース自身がIT業務過誤賠償責任保険に加入している**エピソードで掴む（当事者性・信頼性）。

### 第1部（30分）｜はてなベース担当「中小企業を狙うサイバー攻撃のリアル」
- 「うちは中小だから狙われない」は逆。**大企業への"踏み台"として中小企業が狙われる**（サプライチェーン攻撃の構図。漏洩すれば信用失墜・取引停止・損害賠償）。
- データで裏付け:
  - セキュリティ対策済み企業80%に対し、約7割がマルウェア感染経験（IPA調査）
  - 新種マルウェアは1日約120万件。ブラックリスト型対策では防ぎきれない
  - 大阪商工会議所・神戸大の調査では中小企業30社**全社**に攻撃痕跡（NHK NEWS7報道）
  - 標的型メール訓練の開封率は平均25%（建設・不動産36%等、業種別データ）
- 実務あるある（総務向け）: 私物スマホ・PCの業務利用、フリーWi-Fi、古いブラウザ/OS、退職者アカウントの放置、クラウド会計・kintoneの権限設定ミス
- **明日からできる無料対策**: チェックリストに沿って解説（多要素認証、バックアップ、権限整理、OS更新、訓練）

### 第2部（25分）｜当代理店担当「攻撃されたら、いくらかかる？」
- 事故対応の実額イメージ: ウイルス調査・駆除はPC1台あたり10万円超も。フォレンジック調査、復旧、通知・見舞い、営業停止の逸失利益…
- 例え話（今徳氏トークの転用）: 「会社の生産性を上げた自動車には自賠責＋任意保険が当たり前。今や自動車以上に生産性を担うIT機器が"無保険"で走っている状態です」
- 対策の全体像: 内閣サイバーセキュリティセンター（NISC）の対策レベル1〜5。**レベル1〜4（予防・監視・駆除復旧）をすべて自前で揃えるのは中小企業には非現実的 → だからレベル5「保険加入」が最後の砦**
- サイバー保険で何が出るか（費用・賠償・利益補償の3本柱）を専門用語なしで。保険料の目安レンジも提示（「補償内容や保険料がわからない」が未加入理由の1位40%なので、ここを解消する）

### 第3部（15分）｜対談＋Q&A「経営者がまず着手すべき3つ」
- はてなベース×代理店の対談形式。「対策と保険はどちらが先？」「総務が最初にやるべきことは？」など想定問答を準備。
- 会場・オンラインからの質疑。

### クロージング（5分）
- アンケート記入（下記フォロー動線）＋特典案内。

## 5. フォローアップ動線（ここが本丸）

アンケートに次の3チェックを設け、**2週間以内に個別アポ**:
1. □ 無料簡易セキュリティ診断を受けたい（→はてなベースが対応）
2. □ サイバー保険の簡易見積りが欲しい（→当代理店が対応。決算書不要の簡易試算から）
3. □ 現在の保険契約全体を見直したい（→多種目展開の入口）

- 相互送客ルール: 診断希望者にも保険案内を同封、見積り希望者にも診断案内を同封（両社で事前合意）。
- セミナー録画・資料は後日配布し、欠席者フォローにも活用。

## 9. コンプライアンス・運営上の注意

1. **募集文書審査**: 保険に言及するチラシ・LP・投影資料は事前に保険会社の審査・承認を得る。
2. **役割分担の明確化**: 保険商品の説明・募集行為は募集人資格を持つ代理店側のみが行う。はてなベースは技術・実務パートに限定（構成表に明記）。
3. **不安を煽りすぎない**: 脅威データは出典（IPA・NISC・商工会議所等）を明記し、事実ベースで。恐怖訴求一辺倒でなく「今日からできる無料対策」をセットで示す。
4. **個人情報**: 申込・アンケート情報の両社共有について、申込時に利用目的を明示し同意を取得。
5. **事例の扱い**: 顧客実名事例は許諾を得たもののみ。原則は報道済み事例・統計を使用。
