# 財務セミナー開催マニュアル(汎用版)

商工会議所と連携して開催する「90分財務セミナー → 個別相談 → 共同コンサル受注」の標準手順書です。
地域名・日付・担当者名を差し替えれば、どの商工会議所でも使えます。

---

## 1. 全体像

**流れ(9ステップ)**

企画 → チラシ → 集客 → 準備 → 当日 → 振り返り → 個別相談 → 提案・受注 → 報告

**体制(4つの役割)**

| 役割 | 担当 | 主な仕事 |
|---|---|---|
| 責任者 | (例:小関) | 進行管理・商工会議所との窓口・司会・申込管理 |
| 講師 | (例:富崎さん) | セミナー本編・財務分析・コンサル提案 |
| 商工会議所担当 | (例:桜井さん) | 会場・折り込み・HP掲載・申込受付 |
| サポート | (例:道場生1〜2名) | 受付・写真・記録 |

**標準スケジュール**

| 時期 | やること | 武蔵野の場合 |
|---|---|---|
| 3か月前 | 企画確定・商工会議所と合意 | 7月中 |
| 2か月前 | チラシ完成・折り込み申込・納品 | 8/15申込締切・8/24納品 |
| 1か月前 | 会報発送・申込受付開始 | 9/10 |
| 2週間前 | 資料完成・リハーサル | 9月下旬 |
| 当日 | セミナー開催(2回) | 10/7(水)午後・10/14(水)午前 |
| 翌日 | 振り返り(30分)→第2回に反映 | 10/8 |
| 7〜10日後 | 個別相談 | 10月中〜下旬 |
| 2週間〜1か月後 | 提案・受注 | 11月 |
| 1か月後 | 報告・マニュアル更新 | 11月末 |

---

## 2. 目標と予算の目安

| 項目 | 目安 |
|---|---|
| 申込 | 定員の1.2〜1.5倍(武蔵野:14〜18名) |
| 出席率 | 80%以上 |
| アンケート回収 | 90%以上 |
| 個別相談 | 参加者の3〜4割(武蔵野:4〜6社) |
| 提案 → 受注 | 提案2〜3社 → 受注1〜2社(最低1社) |
| 予算 | 6〜7万円(折込4.4万+会場費+印刷1万+備品0.3万) |

終了後に「総経費 ÷ 受注社数 = 顧客獲得単価」を必ず計算する。

---

## 3. 企画と商工会議所との合意(3か月前まで)

- □ 講師と打合せし、タイトル・90分の構成・個別相談への導線を決める
- □ 商工会議所の担当者にアポを取り、企画書を持って提案する
- □ 開催日(2回)と会場を予約する
- □ 下の「確認リスト」を全部確認し、回答をメモに残す
- □ 予算表と申込者管理表(氏名・会社・連絡先・出欠・相談・受注を1行で管理)を作る

**商工会議所への確認リスト(3分野だけ)**

- □ 会場:料金/使える時間/机椅子の配置/プロジェクター・スクリーン・電源/入館方法/飲食可否
- □ チラシ:サイズ・仕様/部数/折り込み申込の締切/納品場所・方法・期限
- □ 申込:HP掲載日/申込方法/申込者情報をいつ・どう共有してもらうか/個人情報をフォロー連絡に使ってよいか

**90分の基本構成(全開催で共通)**

挨拶5分 → 経営者の悩み10分 → 財務の基本25分 → 事例20分 → 自社診断ワーク12分 → 個別相談案内8分 → 質疑10分

---

## 4. チラシ(2か月前まで)

- □ 原稿を作る(ChatGPT可)→ 講師が内容チェック
- □ Canvaでデザインする(A4・1枚)
- □ 必ず入れる:タイトル/日時/会場/定員/無料/講師写真とプロフィール/個別相談案内/申込QRコード/問い合わせ先
- □ 校正する:日付と曜日/時刻/電話番号/QRコードを実際に読む(ここの間違いが一番多い)
- □ 商工会議所の承認をもらう
- □ 印刷を発注する(納品期限の2日前着で)
- □ 折り込み申込を締切までに提出する ★遅れると開催が飛ぶ
- □ チラシを期限までに納品し、受領確認をもらう ★同上
- □ HP掲載文(チラシと同じ内容)を提出する

---

## 5. 集客と申込管理(1か月前〜前日)

- □ 会報発送日にHP掲載と申込ページを確認する
- □ 申込が来たら管理表に記録し、受付確認メールを送る
- □ 週2回、商工会議所に申込状況を確認する
- □ 2週間前に申込が目標の半分未満なら、追加策を打つ(HP再告知・知人経営者への直接案内・窓口へのチラシ設置)
- □ 1週間前と前日にリマインドメールを送る(前日メールに「決算書か試算表をお持ちいただくと診断がより具体的に(任意)」と一言)

---

## 6. 資料準備とリハーサル(2週間前まで)

**作るもの(5点セット)**

- □ 講師スライド(90分構成どおり)
- □ 自社診断チェックシート(A4・1枚。10問程度のはい/いいえ。「チェックが多い方は個別相談へ」で締める)
- □ アンケート(A4・1枚。満足度/役立った内容/個別相談の希望欄を必ず入れる)
- □ 個別相談の案内(QRコード付き)
- □ 司会メモ(挨拶と個別相談の案内トーク)

**リハーサル**

- □ 90分を通しで1回やる。時間オーバーの箇所と分かりにくい箇所を直す

---

## 7. 当日運営

**前日チェック**

- □ 参加者名簿(最新版)/資料一式(人数+予備5部)/PCとスライド(バックアップをUSBにも)/充電器・延長コード・HDMI変換/名札

**当日の流れ(開始60分前から)**

| 時間 | やること |
|---|---|
| 60分前 | 入館・机椅子の設営・投影テスト・資料を各席へ |
| 30分前 | 受付開始(サポートが名簿チェック・名札渡し) |
| 開始 | 司会挨拶5分 → 講師にバトンタッチ |
| 本編中 | 司会は時間管理、サポートは写真と「反応・質問」のメモ |
| ワーク | 司会が席を回って記入をサポート |
| 案内 | 個別相談を案内し、その場でQRを読んでもらう |
| 終了時 | アンケートをその場で回収(出口でサポートが受け取る) |
| 終了後 | 相談に興味がある人に個別に声かけ → 撤収・原状回復 → 担当者にお礼 |

- □ 終わったら当日中に:出欠を管理表に反映/写真・メモを保存

---

## 8. 振り返り(翌日・30分)

第1回の翌日に必ずやり、第2回に反映する。

- □ 数字:申込/参加/出席率/アンケート回収/個別相談申込/QRを開いた人数
- □ 中身:反応が良かった箇所・悪かった箇所/時間配分のずれ/ワークの使いやすさ/出た質問
- □ 運営:受付・機材・会場で困ったこと
- □ 決める:次回変える点を最大5つ。「何を・誰が・いつまでに」で書き残す

---

## 9. フォローと個別相談(終了後7〜10日以内)

**フォロー**

- □ 参加者に24時間以内にお礼メール(資料+個別相談の再案内つき)
- □ 欠席者に資料と次回・相談の案内
- □ 相談を迷っている人に1回だけ再案内(それ以上は追わない)

**個別相談(60分・参加者限定)**

- □ 日程を決めたら「決算書か試算表を持参(できれば事前送付)」と案内する
- □ 進め方:責任者がヒアリング10分 → 講師が財務分析30分 → 採用・投資・借入の相談10分 → 次のステップ紹介10分
- □ 聞くこと:年商・粗利・営業利益・現預金・借入/試算表を毎月見ているか/経営課題/採用・投資・借入の予定/税理士との関係
- □ 3日以内にA4・1枚の「経営数字診断シート」(現状の数字・課題・アクション3つ)を渡す
- □ 相談ごとに「提案する/しない」を講師と決める

※預かった決算書は厳重保管し、終了後に返却・破棄する。

---

## 10. 提案・受注(相談後2週間以内)

- □ 提案書は相談で聞いた実際の数字と課題から作る(ひな形のまま出さない)
- □ 提案の場で「回答期限」と「次に連絡する日」を決める
- □ 結果(受注・失注)と理由を全件記録する(失注理由が次回の改善材料)
- □ 受注したら:契約 → キックオフ → 事例として紹介してよいか許諾をもらう

---

## 11. 報告と次回へ(1か月後まで)

- □ KPIを集計し、顧客獲得単価を計算する
- □ 商工会議所に開催報告書(実績・参加者の声・写真・お礼)を提出する ※受注金額などは書かない
- □ その場で次回開催を打診する
- □ 気づいた改善点をこのマニュアルに反映する

---

## 12. 横展開のルール(財務道場生向け)

自分の地域で開催したい人は、このマニュアル+武蔵野の実物一式(企画書・チラシ・報告書)を使う。

**単独で講師をやれる基準**

- □ 90分の模擬セミナーで合格評価(時間配分・わかりやすさ・事例・ワーク進行・相談への誘導・質疑対応)
- □ 個別相談のロールプレイ合格
- □ 実開催を1回見学(または録画視聴)

**同行が必要なケース**

- 初回開催 → 小関または富崎さんが同行
- 初めての共同コンサル提案 → 富崎さんが同席
- 基準未達 → 講師は代行し、本人は運営を担当
