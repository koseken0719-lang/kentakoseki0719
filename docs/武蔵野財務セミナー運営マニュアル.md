## 本マニュアルの使い方

- 印刷またはGoogleドキュメントに貼り付けて、完了したタスクの「□」を「■」に変えて運用する。
- まず「マスターチェックリスト」で全体を把握し、日々の実務は各章の詳細チェックリストで管理する。
- 【重要】=プロジェクトの成否に直結するタスク。【期限厳守】=期限を過ぎると開催自体に影響するタスク。
- 各タスクの成果物は、指定フォルダ(01〜24)に必ず保存する。ファイル名は「日付_内容_版数」(例:20260731_セミナー企画書_v1)で統一する。
- 週1回(毎週月曜)、小関が本マニュアルを見て進捗を棚卸しし、遅延タスクには対策を書き込む。

# 第1章 全体概要

## 1-1 プロジェクトの目的

1. 武蔵野商工会議所の会員である中小企業経営者に、財務セミナー(90分×2回)を提供する。
2. セミナー参加者を「自社の数字で考える経営数字の個別診断会」(個別相談)へ誘導する。
3. 個別相談から共同コンサルプランの受注(武蔵野で最低1社、目標1〜2社)につなげる。
4. 一連の流れを再現可能なセミナーモデルとして文書化し、共同コンサルプラン10社獲得に向けて財務道場生が各地域の商工会議所で再現できるようにする。

- □ 振り返りミーティング(30分)を第1回終了翌日までに実施した
- □ 個別相談を7〜10日以内に実施した(初回の共同コンサル提案は富崎さん同席)
- □ 経営数字診断シートを全相談先に渡した
- □ 共同コンサル提案を実施し、結果と理由を記録した
