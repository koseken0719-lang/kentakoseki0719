## 1. 基本設計
- タイトル案: 「うちは大丈夫」が一番危ない。～中小企業のためのサイバー対策と保険の始め方～
- ゴール: 参加者が「明日、総務に指示できる状態」で帰る＋個別相談（診断/見積り/証券診断BID）の獲得
- 時間: 90分（ハイブリッド）
- 役割: 司会・保険パート＝小関（募集人）／実務対策＝はてなベース／（任意）デモ＝カイト or S&J

## 4. 集客チャネル戦略
結論: 本命は「会計事務所・税理士ネットワーク」、次点「スタートアップ支援拠点」。商工会議所・法人会は量、自治体は信用づくりの中期施策。

1. **会計事務所・税理士（本命・即着手）**: はてなベースの既存接点から。税理士が顧問先を集めてくれる構造。税理士事務所自身がハイリスク（電子申告・マイナンバー）で当事者。まず税理士向けミニ勉強会→反応の良い事務所と顧問先向け共催へ。
2. **スタートアップ拠点（第2弾）**: 「大手取引前のセキュリティチェックシート」「調達DD」という具体的な痛み。タイトルは「大手との取引・資金調達の前に整えるセキュリティと保険の最低ライン」。CIC Tokyo、Startup Hub Tokyo、SHIBUYA QWS、VC/アクセラ、freee/kintoneコミュニティ。
3. **商工会議所・法人会・JC（量）**: 支部セミナー枠に企画書持ち込み。共済と競合するため保険色を抑えた「教育セミナー」構成に差し替え。
4. **自治体・公的機関（中期）**: 産業振興課・中小企業振興公社・よろず支援拠点。募集行為不可・リードタイム半年〜。登壇実績と後援名義を取り、他チャネルの営業材料にする。

## 5. 90日アクションプラン
1. 〜2週間: はてなベースと合意、会計事務所3件アポ
2. 〜1ヶ月: 第1回を会計事務所×顧問先向けに小規模開催（台本検証）、募集文書審査
3. 〜2ヶ月: 実績数値を武器にスタートアップ拠点・商工会議所へ持ち込み
4. 〜3ヶ月: 第2回（スタートアップ向け）開催、自治体の次年度啓発事業へ講師登録
