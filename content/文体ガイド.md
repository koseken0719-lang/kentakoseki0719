# 小関健太 文体ガイド

公開済みnote第1弾「なぜ私は、保険を売る前に会社の未来を考えるようになったのか」（2026-08-12公開）を基準とする。
原文は `content/アーカイブ/note第1弾.md` にあり、文体に迷ったら必ずこれを読み直すこと。

## 構成の型

- 冒頭は、読者の頭の中にあるよくある問い（例：「保険営業なのに、なんで財務？」）をフックにする
- 見出しは短い体言止めや素朴な言葉（「北九州の祖父のこと」「消えてしまった関係」）。キャッチーにしすぎない
- 失敗談は出来事だけでなく、**当時の自分の認識のズレ**まで書く（「当時はまだ、どこかでそう思っていました」）。これが最大の個性なので、体験を書くときは必ず入れる
- 締めは「私もまだ途中なので、正解を教えることはできません」という余白で終える

## 文体の特徴

- 1〜3文で改行する短い段落。会話や独白は1行で独立させる
- 「〜なんです」「〜と思っています」「たぶんここです」といった柔らかい口語
- 箇条書きは「・」で、質問形や短い名詞で並べる
- 断定は自分の過去への振り返りにだけ使い（「答えは単純です」）、読者には向けない
- 数字や固有名詞（原価率、紫川、北九州）で具体性を出す
- 大事な一文は段落として独立させる。太字や飾りには頼らない
- 感嘆符はほぼ使わない

## トーン

- 等身大 / 丁寧だが硬すぎない / 少し口語的
- AIっぽい美文にしない / 感動を狙わない / 自己啓発っぽくしない
- 営業臭を出さない / 上から教えない / 過剰な成功物語にしない

## LinkedIn投稿の型（専門投稿）

1. 冒頭に短い問題提起（1〜2行）
2. 自分の経験や現場の話
3. そこから考えたこと
4. 読者が持ち帰れるポイント
5. 必要ならnoteへの導線（「詳しくはコメント欄に」方式）
6. 売り込まずに終わる

800〜1,200字。投稿単体でも価値がある内容にする。

## Threads投稿の型

- 300〜500字。1テーマ1投稿
- 話し言葉寄り。LinkedInの文をそのまま貼らず、短く書き直す
- 問いかけ・小さな気づき・日常のひとことでよい。オチや教訓を無理につけない
