商品を売る → 会社を見る → 数字を見る → 誰から何を学んだか → 現場でどう使うか → 若手営業マンの悩みに答える → 財務道場の思想につながる

## 各弾の骨子メモ

- **第2弾**：初回面談 → 会社を知る → 未来を聞く → 数字を見る → 保険は最後
- **第3弾**：売上・営業利益・現預金・借入・純資産の5項目。数字の説明で終わらず「この数字から、社長に何を聞くのか」まで書く
- **第4弾**：保険営業だけでは会社全体を見られない → 独学 → 決算書を読むだけでは足りない → 富崎さんとの出会い → 「営業利益を残す」「数字を経営判断に使う」に共感 → 現場で見え方が変わった → 一緒に財務道場を運営 → 自分もまだ学ぶ側
- **第5弾**：TOT・ベテランとバッティング → 勝とうとしない → 既存担当者を尊重 → 別の役割を取る（財務・損保・社員・リスク）→「保険担当」ではなく「会社を見る人」になる
- **第6弾**：紹介をお願いする → 相手にメリットがない → 税理士が安心して相談できる人になる → 情報提供 → 結果として紹介が生まれる
- **第7弾**：保険料削減 → 営業利益への影響 → 補償を落としていないか → 財務とリスクの両方を見る
- **第8弾**：何と言うか / 何を聞くか / 既存担当者をどう扱うか / どこまで踏み込むか / 比較されない土俵をどう作るか
- **第9弾**：トップセールスを教えたいわけではない / 自分もまだ実践途中 / 再現性のある法人営業 / 数字で社長と未来を話せる営業マンを増やしたい / 財務道場の存在理由
